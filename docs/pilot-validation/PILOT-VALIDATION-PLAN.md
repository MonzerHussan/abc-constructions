### 5.4 First Transaction Validation (KPI أساسي للماركت بليس)

> **الغرض:** قياس أقوى إشارة على Product-Market Fit في سوق ثنائي — جاهزية **إتمام أول معاملة** عبر المنصة. هذا المؤشر يحدد ما إذا كانت المنصة قادرة فعلاً على توليد صفقات، وليس مجرد اهتمام.

| المؤشر | التعريف | الهدف | المصدر |
|--------|---------|-------|--------|
| FT-01 | **عدد المقاولين لديهم طلب شراء فعلي** | مقاولون يملكون طلباً جاهزاً لشراء مواد خلال Pilot | ≥ 12 من 20 (60%) | سؤال Pilot + مقابلات |
| FT-02 | **عدد الموردين القادرين على تقديم عرض** | موردون يستطيعون إرسال عرض سعر (Quote) لطلبات حقيقية | ≥ 12 من 20 (60%) | سؤال Pilot + مقابلات |
| FT-03 | **عدد المطابقات الناجحة** | صفقات محتملة تم فيها ربط طلب مورداً معاً (Match) | ≥ 6 مطابقات | سجل Pilot |
| FT-04 | **الزمن لأول معاملة** | الوقت من أول تواصل حتى إتمام أول معاملة (أيام) | ≤ 21 يوماً | سجل Pilot |
| FT-05 | **نسبة التحويل من اهتمام إلى طلب فعلي** | (طلبات فعلية ÷ المشاركون المهتمون) × 100 | ≥ 30% | سجل Pilot |

**طريقة القياس:** تُجمع هذه البيانات عبر:
1. سؤال استبياني: "هل لديك حالياً طلب شراء مواد ضمن الـ 3 أشهر القادمة؟" (المقاولون) / "هل تستطيع تقديم عرض سعر (Quote) خلال الـ 3 أشهر القادمة؟" (الموردون)
2. مقابلات المتابعة لتأكيد الجاهزية الفعلية
3. سجل مطابقات الـ Pilot (توصيل الطلبات بالعروض)

**دور المؤشر في القرار:**
- FT-03 ≥ 6 + FT-04 ≤ 21 يوماً → **إشارة قوية PMF** → دعم قرار **Proceed to MVP**
- FT-03 < 3 → **إشارة ضعيفة** → المراجعة الحاسمة قبل Go

### 5.5 قرارات المرحلة — قواعد قرار واضحة (Decision Rules)

> **المنهجية:** القرار النهائي يُبنى على 4 أبعاد مجتمعة: الافتراضات الحرجة + WTP + First Transaction + عدم وجود Failure Thresholds حرجة. المرجع الموحد لقياس النتائج هو **Pilot Success Scorecard**.

#### ✅ PROCEED TO MVP — يُقرَّر إذا تحققت الشروط الأربعة:

| الشرط | التفصيل | الحد الأدنى |
|-------|---------|-------------|
| **1. تحقق الحد الأدنى من Critical Assumptions** | من Scorecard (قسم 3) | ≥ 5 من 6 افتراضات Critical محققة |
| **2. وجود WTP واضح** | S-03 (مقاولون ≥60%) + S-04 (موردون ≥55%) + S-05 (عمولة ≥55%) | جميعها 🟢 أو 🟡 |
| **3. وجود First Transaction Signals** | FT-03 ≥ 3 مطابقات + FT-04 ≤ 21 يوماً | إشارة متوسطة على الأقل |
| **4. عدم وجود Failure Thresholds حرجة** | من معايير الفشل F-01→F-06 | لا يوجد 🔴 في المعايير الحرجة |

> **قاعدة إضافية:** حتى مع تحقق الشروط أعلاه، إذا كان **أي معيار حرج (S-01→S-05) 🔴** → لا PROCEED إلا بعد دراسة السبب.

#### 🔄 MODIFY — يُقرَّر إذا:
- المشكلة **موجودة ومؤكدة** (الألم حقيقي، SMB مؤكدة)، لكن **العرض أو التسعير يحتاج تعديلاً**:
  - WTP ضمن المنطقة الوسطى (40-55%) → تعديل نقاط السعر أو نموذج التسعير
  - قبول العمولة بين 35-55% → تعديل هيكل العمولة أو الاعتماد على الاشتراك
  - الطلب على ميزات مختلفة عن MVP المقترح → تعديل نطاق MVP

#### 🔁 PIVOT — يُقرَّر إذا ظهر **أي** من التالية:
- **ضعف الألم**: تأكيد الألم < 50% (F-04) → المشكلة ليست أولوية
- **عدم وجود استعداد للدفع**: WTP < 40% للمقاولين (F-02) أو عمولة < 35% (F-03)
- **صعوبة خلق سيولة Marketplace**: FT-03 < 3 مطابقات أو FT-02 < 40% → لا يمكن توليد معاملات
- **فشل الشريحة**: جاهزية SMB < 40% (F-05) مع عدم وجود بديل واضح

#### جدول ملخص القرار

| الحالة | القرار |
|--------|--------|
| 5-6 Critical محققة + WTP واضح + FT إيجابي + لا فشل حرج | ✅ **PROCEED TO MVP** |
| الألم مؤكد + WTP في المنطقة الوسطى أو ميزات مختلفة | 🔄 **MODIFY** |
| ألم <50% أو WTP <40% أو FT <3 أو SMB <40% | 🔁 **PIVOT** |
| النتائج مختلطة/غير حاسمة | ⏸️ **تقييم إضافي** (مقابلات مكملة أو إعادة نطاق محدود) |
