# ABC — Feedback Collection Framework

**المرحلة:** Pilot Validation Phase  
**الغرض:** إطار موحد لجمع وتنظيم التغذية الراجعة من المشاركين (استبيانات + مقابلات + تجارب) وتحويلها لقرارات  
**المصدر:** Data Management Procedure (المحور 13 — Market Validation)

---

## 1. قنوات جمع التغذية الراجعة

| القناة | النوع | التوقيت | المخرجات |
|--------|-------|---------|----------|
| **الاستبيانان** (C + S) | كمّي | الأسبوع 3-6 | بيانات كمية + Source Tracking |
| **المقابلات** (Interview Script) | نوعي | الأسبوع 4-6 | قصص + WTP + جاهزية FT |
| **سؤال تقييم نهاية الاستبيان** | كمّي قصير | أثناء الاستبيان | NPS + سهولة الاستبيان |
| **سجل مطابقات FT** | تشغيلي | الأسبوع 5-7 | FT-03, FT-04, FT-05 |
| **ملاحظات فريق التوظيف** | تشغيلي | أسبوعي | عوائق وصول/استجابة |

## 2. استمارة تقييم المشارك (تُضاف في شاشة الشكر — Pilot فقط)

```
ما مدى سهولة فهم أسئلة الاستبيان؟
[1] صعبة جداً  [2] صعبة  [3] متوسطة  [4] سهلة  [5] سهلة جداً

هل لديك أي ملاحظات على صياغة الأسئلة أو وضوحها؟
[نص حر]

ما مدى احتمالية أن توصي منصة ABC لجهة عمل في قطاعك؟
[0-10]
```

> **ملاحظة:** أسئلة التقييم هذه **للـ Pilot فقط** — تُحذف في الإطلاق الكامل.

## 3. تصنيف التغذية الراجعة

### 3.1 حسب النوع

| النوع | التعريف | المثال |
|-------|---------|--------|
| **إشارة PMF إيجابية** | تأكيد ألم/حاجة/استعداد للدفع | "سأدفع 300 شهرياً لو وفّرت لي مقاولين مؤهلين" |
| **إشارة ضعيفة** | اهتمام عام بلا التزام | "فكرة جيدة، ربما أجربها" |
| **إشارة سلبية** | رفض أو حاجز | "العمولة 3% مرتفعة جداً" |
| **عائق تبني** | مشكلة تمنع الاستخدام | "لا وقت لإدارة كتالوج" |
| **اقتراح ميزة** | طلب إضافة | "أحتاج تكامل مع Excel" |

### 3.2 حسب الشريحة

| الشريحة | القرار المتأثر |
|---------|----------------|
| مقاولون | أولوية الميزات، التسعير، نطاق MVP |
| موردون | نموذج الإيراد، Onboarding، عرض القيمة |

---

## 4. مصفوفة التغذية الراجعة → القرار

| إذا وردت تغذية راجعة من النوع... | عندها القرار... |
|-----------------------------------|-----------------|
| WTP مرتفع (نطاق أعلى منتشر) | اعتماد اشتراك مدفوع مبكر |
| WTP منخفض | Freemium قوي + عمولة |
| الألم = RFQ/شفافية (مؤكد بالسلوك) | RFQ Engine + مقارنة كأولوية MVP |
| جاهزية رقمية منخفضة (موردون) | استثمار في خدمة إنشاء الكتالوج |
| مخاوف من العمولة | تقديم Freemium كبديل + توضيح القيمة |
| طلب شراء فعلي متوفر | تسريع تجربة First Transaction |
| اقتراحات متكررة لميزة | إضافة لمصفوفة أولوية الميزات |

## 5. سجل التغذية الراجعة (Feedback Log)

| الحقل | الوصف |
|-------|--------|
| التاريخ | — |

| القناة | استبيان / مقابلة / سجل FT / تقييم |
| نوع التغذية | PMF إيجابي / ضعيف / سلبي / عائق / اقتراح |
| محتوى التغذية | نص مختصر |
| الافتراض المرتبط | P-## / M-## / O-## / F-## |
| القرار المقترح | — |
| الحالة | مفتوح / مُعالج / مؤجل |

## 6. تقرير التغذية الراجعة (أسبوع 8)

| البند | المحتوى |
|-------|---------|
| ملخص الإشارات (إيجابي/ضعيف/سلبي) | نسب لكل شريحة |
| أهم العوائق | قائمة مرتبة |
| الاقتراحات المتكررة | Top 5 |
| خريطة القرارات المتأثرة | افتراض ↔ نتيجة ↔ قرار |
| توصيات نهائية | لتحليل الأسبوع 9 |

---

## 7. معايير نجاح الإطار

| المؤشر | الهدف |
|--------|-------|
| تغذية راجعة موثقة | ≥ 80% من المشاركين |
| تغطية الافتراضات الحرجة | 100% من Critical |
| اقتباسات قابلة للاستخدام | ≥ 10 |
| العوائق المكتشفة | ≥ 3 مميزة |
