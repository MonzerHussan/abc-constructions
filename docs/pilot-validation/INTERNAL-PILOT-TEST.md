# ABC — Internal Pilot Test (اختبار داخلي محدود — 3 مستخدمين)

**المرحلة:** Typeform Build Phase ✅  
**الغرض:** اختبار تجريبي داخلي بثلاثة مستخدمين (عربي/إنجليزي/أوردو) بعد نجاح QA  
**الشرط:** يُنفَّذ بعد `QA-CHECKLIST.md` مكتمل — وقبل أي تواصل خارجي  
**المدة:** جلسة 20-30 دقيقة لكل مستخدم

---

## 1. الفريق (3 مستخدمين اختباريين)

| المستخدم | اللغة | النموذج | السيناريو |
|----------|-------|---------|-----------|
| T1 | العربية | Contractor | مقاول SMB مهتم + FT = نعم |
| T2 | English | Supplier | موزع + FT = نعم + عمولة 1-3% |
| T3 | اردو | Contractor | مقاول + رفض Consent (اختبار الرفض) |

> **القاعدة:** كل مستخدم يستخدم جهازاً مختلفاً (موبايل + لابتوب) للتحقق من التجربة.

---

## 2. أهداف الاختبار الداخلي

| الهدف | كيف يُتحقق |
|-------|-----------|
| وضوح الأسئلة | المستخدم يشرح ما فهمه بعد كل سؤال |
| جودة الترجمة | رصد أي عبارة غامضة/مترجمة خطأ (خاصة الأوردو) |
| سهولة الاستخدام | زمن الإكمال + عدد النقرات + أي إحباط |
| صحة المنطق | مسارات الرفض/القيمة/البريد تعمل |
| صحة الحفظ | التحقق من ورود البيانات في Sheets بالحقول الصحيحة |

---

## 3. سيناريو المستخدم T1 (عربي — مقاول، FT نعم)

| الخطوة | السلوك المتوقع | التحقق |
|--------|----------------|--------|
| 1 | يفتح الرابط `?lang=ar` | تظهر العربية RTL |
| 2 | يختار اللغة: Arabic | language_preference = Arabic |
| 3 | يوافق على Consent | consent_status = granted |
| 4 | يجيب الأسئلة بسرعة ووضوح | لا يطلب توضيحاً |
| 5 | C-12 = "غالباً" | تظهر C-13 |
| 6 | C-V1 يكتب قصة ألم | يُحفظ النص كاملاً |
| 7 | C-24 = 400-1,000 | willingness_to_pay = 400-1,000 |
| 8 | C-V2 = نعم | رسالة تجريبية في النهاية |
| 9 | FT-C = نعم + القيمة 500,000 | ft_order_value = 500,000 |
| 10 | Consent = نعم + بريد | contact_email يُحفظ |
| 11 | يُكمل خلال ≤12 دقيقة | زمن مقبول |

### أسئلة متابعة للمستخدم T1
- هل كانت الأسئلة واضحة بالعربية؟
- هل شعرت بأي سؤال يقودك لإجابة معينة؟
- هل واجهت صعوبة في أي شاشة؟

---

## 4. سيناريو المستخدم T2 (English — مورد، FT نعم)

| الخطوة | السلوك المتوقع | التحقق |
|--------|----------------|--------|
| 1 | يفتح الرابط `?lang=en` | تظهر الإنجليزية LTR |
| 2 | يختار اللغة: English | language_preference = English |
| 3 | يوافق Consent | granted |
| 4 | S-01 = distributor | entity_subtype = distributor |
| 5 | S-12 = No catalog | has_catalog = لا |
| 6 | S-V1 يكتب تكلفة اكتساب | يُحفظ النص |
| 7 | S-24 = 1-3% | commission_acceptance = 1-3% |
| 8 | FT-S = Yes + 250,000 | ft_order_value = 250,000 |
| 9 | Consent = Yes + email | contact_email يُحفظ |
| 10 | يُكمل ≤12 دقيقة | زمن مقبول |

### أسئلة متابعة للمستخدم T2
- Was the English translation clear and natural?
- Any question confusing or leading?
- Any layout/RTL issue on your device?

## 5. سيناريو المستخدم T3 (اردو — مقاول، رفض Consent)

| الخطوة | السلوك المتوقع | التحقق |
|--------|----------------|--------|
| 1 | يفتح الرابط `?lang=ur` | تظهر الأوردو RTL |
| 2 | يختار اللغة: اردو | language_preference = Urdu |
| 3 | يقرأ نص Consent بالأوردو | يقرأه ويكتفي بالشرح |
| 4 | **يرفض** Consent | **ينتهي الاستبيان فوراً** |
| 5 | لا يُحفظ أي بيانات | Sheets بلا صف لهذا المستخدم |
| 6 | يظهر نص الشكر القصير | رسالة لطيفة |

### أسئلة متابعة للمستخدم T3
- کیا اردو ترجمہ واضح تھا؟ (هل كانت الترجمة الأوردو واضحة؟)
- کیا کسی سوال یا ترجمہ میں مسئلہ تھا؟ (هل واجهت مشكلة في أي سؤال أو ترجمة؟)
- کیا اسٹیپس پر عمل کرنا آسان تھا؟ (هل كان التنقل سهلاً؟)
