# 06 — التوصية النهائية (Final Recommendation)

> بناءً على 01–05. هذا المستند يحتاج تصويت G1/G2 ثم G3 لبدء التنفيذ.

## 1. التوصية: **الدمج (Hybrid) — ترحيل استهلاكي، لا إعادة بناء**

1. **اعتماد هوية الـ Pack كاملة:** Amber+Navy، Tokens (مطابقة أصلاً)، الطباعة الثلاثية، مكتبة المكوّنات، أنماط الحالات/الشارات.
2. **ترحيل صفحات `src/` الحالية إلى Tokens والمكوّنات** — الحفاظ على الوظائف والبيانات والمسارات، وتغيير الطبقة البصرية فقط.
3. **إغلاق ثغرات التوطين قبل البصر:** ترحيل ternaries → القاموس (D10)، استكمال الأردية (R3)، مرآة الأيقونات الاتجاهية.
4. **توسيع النمط لغير المغطى:** Auth، Procurement التفصيلي، Organization/Verification/Settings/Delivery/Survey، Research — تعالج بـ Theme فقط دون شاشات جديدة من الـ Pack.
5. **بوابات جديدة (المصنع 07، AI 08) تنتظر sprints لاحقة مستقلة** بعد G3، وليست ضمن الترحيل.
6. **الشعار:** تُحجز مساحات placeholder وتُستبدل فور استلام SVG الرسمي — لا نشر عام قبله.

## 3. نطاق Sprint 1b المقترح (بعد G3)

**الموجة 1 — Theme Rollout (آمن، بلا إعادة بناء)**
- تطبيق Tokens على كل الصفحات (استبدال `bg-blue-500`, `bg-green-500`, `text-gray-*` بـ Tokens).
- توحيد أزرار CTA (primary amber / secondary navy / outline / ghost).
- مرآة الأيقونات الاتجاهية عبر مكوّن `Icon` يغلّف flip.

**الموجة 2 — مكوّنات البيانات**
- ترحيل الجداول إلى table kit + Skeleton بدل نصوص التحميل + EmptyState موحّد.
- توحيد StatusBadge في كل الحالات.

**الموجة 3 — التنقل والهيكل**
- قرار Q1 → Sidebar (نموذج البوابة) أو Navbar محسّن.
- LanguageSwitcher ثلاثي موحّد في كل الهياكل.

**الموجة 4 — التعريب (D10/R3)**
- مسح ternaries → translations.ts (يعتمد `useLanguage` فقط).
- استكمال الأردية لكل السلاسل عبر glossary.md.
- تشغيل D11 matrix (ar/en/ur × rtl/ltr × mobile/desktop) لكل صفحة مرحَّلة.

## 4. قبول الخروج (Definition of Done) لكل موجة

- [ ] `npm run build` ناجح · `npm run test` بلا كسور.
- [ ] كل صفحة مرحَّلة تعمل في اللغات الثلاث (فحص SSR للـ dir/lang + تعريب كامل بلا ternaries).
- [ ] فحص D11 matrix موثّق لكل منطقة.
- [ ] لا خلط ألوان CTA في أي سياق.
