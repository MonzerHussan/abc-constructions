# 10 — مواصفة التخطيط المتجاوب (Responsive Layout Specification)

> القواعد المتجاوبة عبر المنصة. مرجع التنفيذ لـ Sprint 1b + قياس الصفحات في الـ Pack (معاينة جوال 390px).

## 1. نقاط الانكسار (Breakpoints) — Tailwind 4

| الاسم | العرض | الغرض |
|---|---|---|
| `sm` | ≥640px | هواتف كبيرة/أعمدة جزئية |
| `md` | ≥768px | تابلت: أعمدة KPI 2→3 |
| `lg` | ≥1024px | ظهور الـ Sidebar (إن اعتمد في Q1)؛ أعمدة 4+ |
| `xl` | ≥1280px | `max-w-7xl` يساوي العرض الكامل للبوابات |

**القاعدة الحالية في `src/`:** أنماط `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` موجودة بكثافة — بنية سليمة تُحافَظ عليها، وتُوحَّد فحسب.

## 2. الهياكل الثلاثة (إن اعتمد Sidebar في Q1)

| النطاق | الهيكل |
|---|---|
| **Landing & Auth** | بلا Sidebar — Navbar أعلى + محتوى مركزي |
| **بوابات الأدوار** (مقاول/مورد/مصنع/إدارة...) | Sidebar Navy 240px (lg+) → **Sheet/Drawer** تحت lg (من `end`/اليسار في RTL) |
| **عمق العمل** (نماذج/جداول) | تخطيط عمود واحد، حقول مكدّسة، أزرار أسفل الشاشة (ثابتة أحياناً) |

## 3. قواعد المكوّنات

| المكوّن | موبايل (<768) | سطح المكتب (≥1024) |
|---|---|---|
| KPI Cards | `grid-cols-2` (كما الحالية) | `lg:grid-cols-5` (procurement) أو 4 (غيره) |
| بطاقات المنتج/الوحدات | عمود واحد | 2–3 أعمدة |
| الجداول الكثيفة | **تحويل لبطاقات** أو تمرير أفقي بعناية `overflow-x-auto` + `tabular-nums` | جدول كامل |
| أزرار CTA المزدوجة (procurement) | مكدّسة/قائمة | صف واحد end |
| نماذج | حقول بعرض 100%، أزرار شاشة كاملة | شبكة max-w مع محاذاة |
| تنقّل أعلى | Navbar: شعار + switcher + قائمة hamburger | قائمة كاملة |

## 4. قواعد RTL في التجاوب (D11 المدمج)

- المسافات عبر `ps-/pe-/ms-/me-` أو `gap` — لا `pl/pr` الثابتة في المكونات الجديدة.
- الـ Drawer يخرج من `inline-end` (يمين AR/UR، يسار EN).
- الجداول تعكس اتجاه الأعمدة تلقائياً بـ `dir`؛ فرز/ترقيم بلا اتجاهات مثبتة.
- الأرقام (أسعار، كميات) تُعرض ثابتة الاتجاه `dir="ltr"` مع `unicode-bidi: plaintext` عند الحاجة داخل خلط نص عربي+رقم.

## 5. حالات النصوص الثلاثية في التجاوب

| الحالة | القاعدة |
|---|---|
| نص أردية طويل (Nastaliq) | `line-height 1.7`، سماح بتمرير رأسي في الجداول، لا `truncate` لأسماء المنتجات |
| أزرار بلغات طويلة | `white-space: normal` + التفاف داخلي؛ اختصار بضبط أحجام الخطوط لا بالقص |
| أرقام ur-PK | `formatCurrency('ur-PK')` كما في `utils.ts` |
| مقارنة النصوص | حد أدنى/أقصى لأطوال السلاسل في glossary.md — يمنع انكسار التخطيط |

## 6. معاينة الـ Pack كمرجع

- الـ Pack يوفر **تبديل إطار 390px** لكل الشاشات مع إخفاء الـ Sidebar → هو المرجع البصري لسلوك الموبايل لكل بوابة (02، 03، 05...).
