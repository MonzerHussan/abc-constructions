## 1. Data Owner — مسؤول جودة البيانات

### التعيين

| الدور | المسؤول | المسؤوليات |
|-------|---------|------------|
| **Data Owner** | [اسم الشخص/الفريق] | المسؤول الأول عن جودة البيانات |
| **Data Steward** | [اسم الشخص/الفريق] | التنفيذ اليومي لفحوصات الجودة |
| **Data Analyst** | [اسم الشخص/الفريق] | إعداد Clean Dataset والتحليل |

### مسؤوليات Data Owner

1. الموافقة على إجراءات جودة البيانات قبل بدء الجمع
2. مراجعة تقارير الجودة اليومية خلال الـ Pilot
3. اتخاذ القرار بشأن استبعاد الردود غير الصالحة
4. الموافقة على أي تعديل في الاستبيانات (يُوثق في CHANGELOG-PILOT.md)
5. إصدار شهادة جودة البيانات (Data Quality Certificate) قبل التحليل النهائي

## 2. فحوصات جودة البيانات (Data Quality Checks)

### 2.1 Duplicate Responses — الردود المكررة

| المعيار | طريقة الكشف | الإجراء |
|---------|------------|---------|
| نفس عنوان IP + نفس الإجابات الرئيسية | تجميع حسب IP وإجابات الأسئلة الديموغرافية | الاحتفاظ بأول رد فقط، واستبعاد المكرر |
| نفس البريد الإلكتروني (إذا تم إدخاله في سؤال التواصل) | تطابق البريد الإلكتروني | دمج أو استبعاد المكرر |
| نفس التوقيت الزمني (أقل من دقيقة بين ردين) | ختم زمني (Timestamp) | استبعاد الثاني |

### 2.2 Invalid Responses — الردود غير الصالحة

| النوع | طريقة الكشف | الإجراء |
|-------|------------|---------|
| **Straight-lining** | نفس الإجابة لكل الأسئلة (مثلاً كلها "نعم") | استبعاد الرد |
| **Speeders** | وقت الإجابة < 30% من المتوسط لكل استبيان | استبعاد الرد (غير موثوق) |
| **Inconsistent logic** | إجابات متناقضة (مثلاً S-13 = "لا يوجد نظام" و S-15 = "نستخدم ERP") | استبعاد أو مراجعة يدوية |
| **Nonsensical open text** | نص عشوائي في حقل "أخرى" (مثلاً "asdfgh") | استبعاد الحقل فقط |
| **Incomplete** | توقف قبل إكمال 50% من الأسئلة | استبعاد الرد |

### 2.3 Daily Quality Dashboard — لوحة الجودة اليومية

| المقياس | المصدر | الحد الأدنى | التنبيه |
|---------|--------|-------------|---------|
| عدد الردود الجديدة | Typeform Export | متفاوت حسب اليوم | إذا 0 → متابعة التوزيع |
| معدل الإكمال | (أكملوا/بدأوا) × 100 | ≥ 70% | إذا < 60% → مراجعة فورية |
| متوسط الوقت | Typeform | 8-12 دقيقة | إذا > 15 دقيقة → تبسيط |
| % مستقيمين (Straight-liners) | تحليل إحصائي | ≤ 5% | إذا > 10% → مراجعة الصياغة |
| % منسحبين لكل سؤال | Typeform Analytics | ≤ 5% | إذا > 10% → مراجعة السؤال |

## 3. سير عمل البيانات (Data Workflow)

```
                      ┌─────────────────┐
                      │  Typeform Raw    │
                      │  Responses       │
                      └────────┬────────┘
                               │
                               ▼
                      ┌─────────────────┐
                      │  Raw Export     │  ← حفظ بدون تعديل (نسخة أصلية)
                      │  (CSV / Excel)  │
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │  Data Quality   │  ← الفلترة حسب المعايير أعلاه
                      │  Checks         │
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │  Clean Dataset  │  ← للتحليل (بدون المكرر/غير الصالح)
                      │  (analysis.csv) │
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │  Data Dictionary│  ← تعريف المتغيرات
                      │  Variables      │
                      └────────┬────────┘
                               │
                      ┌────────▼────────┐
                      │  Analysis       │
                      │  Segmentation   │
                      │  Pain Points    │
                      │  Feature Matrix │
                      │  WTP Analysis   │
                      └─────────────────┘
```

### 3.1 Raw Data — النسخة الأصلية

| العنصر | الإجراء |
|--------|---------|
| الحفظ | نسخة PDF + CSV من Typeform فور التصدير |
| التسمية | `ABC_PILOT_RAW_[DATE].csv` |
| الموقع | مجلد `data/raw/` |
| التعديل | **ممنوع التعديل** — لأغراض التدقيق والمراجعة |
| الاحتفاظ | طوال مدة المشروع + سنة بعد الإغلاق |

### 3.2 Clean Dataset — نسخة التحليل

| العنصر | الإجراء |
|--------|---------|
| الإنشاء | نسخة من Raw بعد تطبيق فحوصات الجودة |
| التسمية | `ABC_PILOT_CLEAN_[DATE].csv` |
| الموقع | مجلد `data/clean/` |
| التعديل | مسموح فقط بتوثيق التغييرات في سجل التعديلات |
| توثيق الاستبعاد | ملف منفصل `ABC_PILOT_EXCLUDED_[DATE].csv` مع سبب الاستبعاد |

### 3.3 سجل التعديلات على البيانات

أي تعديل على البيانات يجب توثيقه:

| التاريخ | السجل | سبب التعديل | من قام به |
|---------|-------|-------------|-----------|
| [تاريخ] | استبعاد رد ID-042 | مكرر حسب IP | [الاسم] |
| [تاريخ] | استبعاد رد ID-087 | Speedster (3 دقائق لمتوسط 10 دقائق) | [الاسم] |
| [تاريخ] | تصحيح قيمة S-15 | خطأ إدخال (ERP → لا) | [الاسم] |

## 4. Data Dictionary — قاموس البيانات

يتم إنشاء قاموس بيانات لكل استبيان يحدد:

| الحقل | الوصف | النوع | القيم المسموحة | ملاحظات |
|-------|-------|-------|----------------|---------|
| `response_id` | معرف فريد لكل رد | String | UUID | يولده Typeform تلقائياً |
| `timestamp` | تاريخ ووقت الإجابة | DateTime | ISO 8601 | — |
| `source` | قناة الوصول (السؤال 0) | Categorical | linkedin, whatsapp, referral, email, association, other | Source Tracking |
| `q1` | نوع النشاط | Categorical | [حسب الاستبيان] | — |
| `q2` | حجم الشركة | Ordinal | 1-5 (من <10 إلى >500) | — |
| ... | ... | ... | ... | ... |
| `consent` | الموافقة على التواصل | Boolean | yes, no | — |
| `contact` | معلومات التواصل | String | نص حر | اختياري — يُحذف من Clean Dataset للخصوصية |

### ترميز الأسئلة

| البادئة | الاستبيان |
|---------|-----------|
| `C_` | Contractors (أسئلة 1-26) |
| `S_` | Suppliers (أسئلة 1-27) |
| `E_` | Engineers (أسئلة 1-23) |
| `W_` | Workforce (أسئلة 1-24) |
| `T_` | Training (أسئلة 1-23) |

مثال: `C_05` = Contractors السؤال 5 (أدوات إدارة المشاريع)

### Ethical Data Handling

| المبدأ | الإجراء |
|--------|---------|
| **الموافقة** | تم أخذ الموافقة عبر سؤال التواصل الختامي |
| **الخصوصية** | يتم إزالة معلومات التواصل (الاسم، البريد، الهاتف) من Clean Dataset قبل التحليل |
| **الاحتفاظ** | Raw Data محفوظة بشكل آمن مع تقييد الوصول |
| **الحذف** | يتم حذف جميع البيانات الشخصية بعد سنة من انتهاء المشروع |
| **الإبلاغ** | كل النتائج مجمعة — لا يوجد إفصاح عن فرد واحد |
