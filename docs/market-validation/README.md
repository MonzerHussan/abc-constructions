## تعليمات النشر (Google Forms / Typeform)

1. **لغة الاستبيان:** كل استبيان بالعربية مع عناوين إنجليزية
2. **الوقت المتوقع للإكمال:** 8-12 دقيقة لكل استبيان
3. **الأسئلة الإجبارية:** جميع الأسئلة مغلقة ما عدا سؤال "ملاحظات" الأخير + سؤال الجنسية (W-04)
4. **الأسئلة الشرطية (Conditional Logic):** إخفاء الأسئلة غير المناسبة بناءً على إجابة سابقة
5. **تقسيم الأقسام:** استخدام أقسام (Sections) في النموذج الإلكتروني لكل قسم
6. **شاشة ترحيبية:** شرح الغرض + الوقت المتوقع + ضمان السرية
7. **شاشة شكر:** رابط التسجيل في القائمة البريدية للحصول على نتائج الدراسة
