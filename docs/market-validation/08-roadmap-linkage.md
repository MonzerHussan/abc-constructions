## نظام قياس الأثر (Impact Measurement)

بعد جمع البيانات، سنستخدم هذه المصفوفة لتحديد:

1. **Priority Score لكل ميزة** = المجموع المرجح للإجابات المغذية
2. **Confidence Level** = عدد الإجابات ÷ العدد المستهدف لكل شريحة
3. **Decision Gates**:
   - Priority Score ≥ 80 → MVP
   - 50-79 → Phase 2
   - < 50 → Re-evaluate أو Postpone
