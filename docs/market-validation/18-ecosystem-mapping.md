## 2. أطراف المنظومة — القيمة، الإيراد، العلاقات

### 2.1 Users (المشترون / الأفراد)

| البند | التفاصيل |
|-------|---------|
| **التعريف** | أفراد ومستهلكون يبحثون عن مواد أو خدمات |
| **القيمة من ABC** | الوصول لسوق مواد وموردين موثوقين |
| **مصدر الإيراد لـ ABC** | منخفض مباشرة — لكن يغذي الطلب على المنصة |
| **العلاقات** | يشتري من: Suppliers, Manufacturers, Contractors |
| **بيانات الـ Pilot** | [عدد المستجيبين، احتياجاتهم] |
| **القرار التجاري** | هل نخدم الأفراد في MVP أم نركز على B2B؟ |

### 2.2 Suppliers (الموردون وتجار الجملة)

| البند | التفاصيل |
|-------|---------|
| **التعريف** | تجار جملة، موزعون، وكلاء — أطراف البيع الرئيسية |
| **القيمة من ABC** | وصول لعدد أكبر من المقاولين والمشترين، إدارة RFQ رقمية |
| **مصدر الإيراد لـ ABC** | 🔑 اشتراكات + عمولة على المبيعات |
| **العلاقات** | يبيع لـ: Contractors, Users / يستلم من: Manufacturers |
| **بيانات الـ Pilot** | [S-01, S-06, S-07, S-08, S-21, S-22, S-23, S-24, S-25] |
| **القرار التجاري** | نموذج Freemium أم اشتراك؟ نسبة العمولة؟ |

### 2.3 Manufacturers (المصانع والمنتجون)

| البند | التفاصيل |
|-------|---------|
| **التعريف** | منتجون مباشرون (أسمنت، حديد، خرسانة، تشطيب) |
| **القيمة من ABC** | قناة بيع مباشرة، بيانات طلب، إدراج المنتجات |
| **مصدر الإيراد لـ ABC** | 🔑 عمولة أعلى + اشتراكات Premium + إعلانات |
| **العلاقات** | يبيع لـ: Suppliers, Contractors / يزود: Marketplace بالمنتجات |
| **بيانات الـ Pilot** | [S-01 (نوع النشاط - مصنع), حجم النشاط] |
| **القرار التجاري** | هل نستهدف المصانع كشريحة مستقلة أم ضمن الموردين؟ |

### 2.4 Contractors (المقاولون)

| البند | التفاصيل |
|-------|---------|
| **التعريف** | مقاولو عامة وتخصص — المستهلك الأساسي للمواد والخدمات |
| **القيمة من ABC** | شراء أسهل، موردون موثوقون، RFQ أسرع، توظيف أسهل |
| **مصدر الإيراد لـ ABC** | 🔑 اشتراكات (Freemium → مدفوع) |
| **العلاقات** | يشتري من: Suppliers, Manufacturers / يوظف: Workforce / يتعاقد: Training |
| **بيانات الـ Pilot** | [C-01, C-02, C-03, C-09, C-10, C-21, C-22, C-23, C-24] |
| **القرار التجاري** | الحجم المستهدف (SMB vs Enterprise)، نموذج الاشتراك |

### 2.5 Workforce (الكفاءات والقوى العاملة)

| البند | التفاصيل |
|-------|---------|
| **التعريف** | مهندسون، مشرفون، فنيون، عمال مهرة |
| **القيمة من ABC** | وظائف مناسبة، تدريب، شهادات، نمو مهني |
| **مصدر الإيراد لـ ABC** | منخفض مباشرة — لكن يزيد جاذبية Jobs Platform للشركات |
| **العلاقات** | يعمل لـ: Contractors / يتدرب لدى: Training Providers |
| **بيانات الـ Pilot** | [W-01, W-06, W-07, W-08, W-14, W-15, W-18, W-20] |
| **القرار التجاري** | هل Jobs مجانية للكفاءات؟ كيف نستثمر في بياناتهم؟ |

### 2.6 Training Providers (مقدمو التدريب)

| البند | التفاصيل |
|-------|---------|
| **التعريف** | معاهد تدريب، مراكز تطوير مهني، مقدمي شهادات |
| **القيمة من ABC** | وصول لمتدربين مستهدفين، تقنية، شهادات رقمية |
| **مصدر الإيراد لـ ABC** | 🔑 عمولة على التسجيلات (Revenue Share) |
| **العلاقات** | يدرب: Workforce / يتعاقد مع: Contractors (تدريب مؤسسي) |
| **بيانات الـ Pilot** | [T-06, T-07, T-10, T-11, T-16, T-17, T-18, T-20] |
| **القرار التجاري** | نموذج الشراكة، نسبة العمولة، الحصرية |

### 2.7 Partners (الشركاء الاستراتيجيون)

| البند | التفاصيل |
|-------|---------|
| **التعريف** | جمعيات مهنية، غرف تجارية، جهات حكومية، مقدمي خدمات مالية |
| **القيمة من ABC** | بيانات السوق، منصة لخدمة أعضائهم |
| **مصدر الإيراد لـ ABC** | 🔑 شراكات تجارية، رسوم تكامل، تقاسم بيانات |
| **العلاقات** | يربط: ABC بالأسواق والجهات الرسمية |

| **القرار التجاري** | من نستهدف كشركاء؟ ما هيكل الشراكة؟ |

## 4. العلاقات البينية — قيمة ABC لكل علاقة

| العلاقة | القيمة الحالية (المشكلة) | قيمة ABC (الحل) | المؤشر من Pilot |
|---------|--------------------------|-----------------|----------------|
| **مورد ← مقاول** | بحث يدوي، أسعار غير شفافة | Marketplace + RFQ + مقارنة | C-10, S-09 |
| **مقاول ← مورد** | صعوبة إيجاد موثوقين | Supplier Verification + Reviews | C-10, C-11 |
| **مصنع ← موزع** | قنوات بطيئة | قناة رقمية مباشرة + بيانات | S-01, S-08 |
| **مقاول ← كفاءة** | توظيف صعب وبطيء | Jobs Platform + Matching | C-15, W-08 |
| **كفاءة ← مقاول** | قلة فرص مناسبة | وظائف محدثة + ملفات مهنية | W-07, W-08 |
| **كفاءة ← تدريب** | لا يعرف من يتدرب عنده | Training Marketplace + تقييمات | W-13, W-14 |
| **مقاول ← تدريب** | لا يجد دورات مناسبة | Corporate Training + تقييمات | C-19 |
| **مورد ← إعلان** | تسويق مكلف وغير مستهدف | Ads مدعومة بالبيانات | S-19, S-20 |

## 6. الأسئلة التجارية التي يجيب عنها الـ Pilot

| السؤال | المعطيات من Pilot | القرار النهائي |
|--------|------------------|----------------|
| من نستهدف أولاً؟ (Suppliers أم Contractors) | حجم الطلب + الجاهزية في C-22, S-21 | أولوية القناة الأولى |
| هل نخدم الأفراد (B2C)؟ | % أفراد في S-06 | نطاق MVP |
| ما نموذج الاشتراك للموردين؟ | S-23, S-24 | Pricing Strategy |
| ما نسبة العمولة للموردين؟ | S-24 | Financial Model |
| هل نستهدف المصانع من البداية؟ | % مصانع في S-01 + اهتمامهم | نطاق Supplier Network |
| ما سعر دورات الأفراد؟ | W-15 | Training Pricing |
| ما نموذج شراكة التدريب؟ | T-17, T-18 | Revenue Share Rate |
| هل نحوّل Workforce لبيانات ثمينه؟ | W-20 (مشاركة بيانات) | Data Strategy |
