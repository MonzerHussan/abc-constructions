# Pilot Dashboard Structure

## هيكل لوحة متابعة بيانات الـ Pilot

**الغرض:** لوحة بيانات تفاعلية لمراقبة جودة ونتائج الـ Pilot فورياً.

---

## 1. جمع البيانات (طبقة الاستقبال)

### 1.1 مصادر البيانات

| المصدر | التنسيق | التكرار | الموقع |
|---------|---------|---------| ------ |
| Typeform Export | CSV / JSON | يومي (يدوي) | `data/raw/` |
| Google Sheets (إن وجد) | CSV | فوري | `data/raw/` |
| Manual Logs (مقابلات) | CSV | عند الإجراء | `data/manual/` |

### 1.2 ملفات البيانات

| الملف | المحتوى | طريقة الإنشاء |
|-------|---------|--------------|
| `ABC_PILOT_RAW_[DATE].csv` | جميع الردود الخام | تصدير Typeform |
| `ABC_PILOT_CLEAN_[DATE].csv` | ردود صالحة فقط | بعد فحوصات الجودة |
| `ABC_PILOT_EXCLUDED_[DATE].csv` | ردود مستبعدة + السبب | بعد فحوصات الجودة |
| `ABC_PILOT_DICTIONARY.csv` | قاموس المتغيرات | تعريف لكل سؤال |

## 2. مراقبة الجودة (لوحة التحكم)

### 2.1 Quality KPIs

| المؤشر | الصيغة | الهدف | الحالي | الحالة |
|--------|--------|-------|--------|--------|
| **Completion Rate** | `أكملوا / بدأوا` | ≥ 70% | [Pilot] | 🟢 / 🟡 / 🔴 |
| **Average Time** | `متوسط وقت الإكمال` | 8-12 د | [Pilot] | 🟢 / 🟡 / 🔴 |
| **Drop-off Rate** | `انسحبوا عند سؤال X / المجموع` | ≤ 5% | [Pilot] | 🟢 / 🟡 / 🔴 |
| **Invalid Rate** | `غير صالح / الإجمالي` | ≤ 10% | [Pilot] | 🟢 / 🟡 / 🔴 |
| **Straight-line %** | `جميع الإجابات متطابقة` | ≤ 5% | [Pilot] | 🟢 / 🟡 / 🔴 |
| **Source Coverage** | `توزيع قنوات الوصول` | كل القنوات ممثلة | [Pilot] | 🟢 / 🟡 / 🔴 |
