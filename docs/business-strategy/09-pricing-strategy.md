# ABC — Pricing Strategy

**الغرض:** تحديد نموذج تسعير منتجات ABC وخدماتها بما يعكس القيمة ويتوافق مع WTP  
**الحالة:** قالب مبدئي — تُضبط النقاط بعد Pilot  
**العملة:** درهم إماراتي (AED)

---

## 1. أهداف التسعير

| الهدف | الأولوية |
|-------|----------|
| تحقيق نموذج إيراد مستدام | عالية |
| تشجيع التبني المبكر | عالية |
| موازنة بين جانبي السوق | متوسطة |
| التوافق مع WTP (Pilot) | عالية |
| التميز عن المنافسين | متوسطة |

---

## 2. نموذج التسعير (مبني على منهجية Value-Based Pricing)

### 2.1 المبادئ

| المبدأ | التطبيق |
|--------|---------|
| **قيمة أولاً** | التسعير يعكس قيمة الميزة (RFQ، وصول، بيانات) |
| **تسعير تدريجي** | Freemium → Basic → Pro (تحويل تصاعدي) |
| **موازنة الثنائية** | إبقاء المشترين (مقاولين) بشرط جيد لتغذية العرض |
| **مبني على WTP** | نقاط محددة من Pilot (C-23/C-24, S-23/S-24) |

### 2.2 شرائح التسعير (مبدئية — تُضبط بعد Pilot)

#### للموردين (Suppliers)

| الخطة | السعر الشهري | الميزات |
|-------|--------------|---------|
| **Freemium** | 0 | كتالوج أساسي، عدد محدود من المنتجات، غير مرئي في البحث |
| **Basic** | 250-400 | كتالوج ممتد + ظهور في البحث + RFQ ردود |
| **Pro** | 500-800 | كل ميزات Basic + Featured + تقارير + دعم أولوية |
| **Enterprise** | مخصص | تكاملات + حسابات متعددة + واجهة API |

#### للمقاولين (Contractors)

| الخطة | السعر الشهري | الميزات |
|-------|--------------|---------|
| **Freemium** | 0 | تصفح + مقارنة محدودة + 5 RFQ شهرياً |
| **Basic** | 150-300 | RFQ غير محدود + تنبيهات + سجل أسعار |
| **Pro** | 400-600 | كل Basic + تقارير مشاريع + دعم مخصص |

---

## 3. نماذج الإيراد والتسعير المزدوج (بالنسبة المئوية)

| النموذج | التطبيق | النسبة المبدئية |
|---------|---------|-----------------|
| **اشتراكات** | موردون + مقاولون | 10-15% من الإيراد |
| **عمولة صفقة** | 3% (نطاق Pilot S-24: 1-5%) | 70-85% |
| **Featured Listings** | ترقية الموردين | 5-10% |
| **إعلانات** | B2B targeted | 3-5% |
| **تدريب/شراكات** | تمويل صغروي/تدريب | 1-3% |
| **خدمات/AI** | Phase 3 | 0-3% |

> **⚠️ توحيد مع Revenue Model (المحور 10):** النسب أعلاه **أهداف إستراتيجية للتنويع**. النموذج المالي الفعلي (المحور 7/10) يُظهر العمولة بنسبة 89-92% في السنوات الثلاث بسبب فرضيات GMV. **الفجوة تُعالج** برفع تحويل Freemium→Paid وتعزيز Featured/AI — الهدف خفض حصة العمولة إلى أقل من 80% بسنة 3.

---

## 4. منهجية ضبط الأسعار (عملية التحقق بعد Pilot)

| الخطوة | النشاط |
|--------|--------|
| 1 | قياس WTP من Pilot (نقاط مشتقة) |
| 2 | مقارنة مع تكاليف اكتساب (CAC) |
| 3 | اختبار حساسية الأسعار (A/B) |
| 4 | ضبط النقاط حسب LTV:CAC |

---

## 5. استراتيجيات التسويق السعري

| الميزة | التطبيق |
|--------|---------|
| **خصم التبني المبكر** | 6 أشهر مجاناً أو خصم 50% لأول 50 مورد |
| **حزمة سنوية** | خصم شهرين (على سنوي) |
| **مكافأة الإحالة** | خصم على الإحالة الناجحة |
| **تجميع** | باقات اشتراك + خدمات مجمعة |

---

## 6. مقارنة مع المنافسين (إطار)

| المنافس | النموذج |
|---------|---------|
| Tradeling | عمولة صفقة |
| منصات B2B أخرى | اشتراك + عمولة |
| WhatsApp/Direct | بدون تكلفة (منافسة على السعر) |

> **التمايز:** تقديم Freemium حقيقي مع قيمة محسوسة قبل الدفع — نقطة تفوق على المنافسين.

---

## 7. مؤشرات المراقبة بعد الإطلاق

| المؤشر | الهدف |
|--------|-------|
| تحويل Freemium→Paid | 15-25% |
| متوسط الإيراد/عميل | ≥ ARPU المستهدف |
| توزيع الخطط | توازن Basic/Pro |
| رضا الموردين عن العمولة | ≥80% |
