# ABC — Risk Assessment

**الغرض:** تحديد وتقييم المخاطر المحتملة لمشروع ABC مع خطط التخفيف  
**المنهجية:** مصفوفة الاحتمالية × الأثر + خطة تخفيف لكل خطر

---

## 1. مصفوفة تقييم المخاطر

| المستوى | القيمة | النطاق |
|---------|--------|--------|
| منخفض (Low) | 1 | أثر/احتمال منخفض |
| متوسط (Medium) | 2 | أثر/احتمال متوسط |
| مرتفع (High) | 3 | أثر/احتمال مرتفع |

> **درجة الخطر = الاحتمالية × الأثر** (1-9)

## 3. تحليل المخاطر ذات الأولوية العالية (R1, R2)

### 3.1 R1 — تبني منخفض من الموردين (الدرجة 9)

**المخاطر:** الموردون لا يسجلون أو لا يستخدمون المنصة.

| الجذر | المؤشر | خطة التخفيف |
|-------|--------|-------------|
| قلة فهم القيمة | معدل تسجيل منخفض | وضوح عرض القيمة (قناة بيع B2B) |
| تكلفة/مخاوف | تعثر Onboarding | برنامج مجاني أول 6 أشهر |
| عدم توفر وقت | ضعف النشاط | فريق ميداني + خدمة إنشاء كتالوج |

### 3.2 R2 — ضعف نشاط الصفقات (GMV) (الدرجة 9)

**المخاطر:** تسجيل لكن بدون صفقات فعلية.

| الجذر | المؤشر | خطة التخفيف |
|-------|--------|-------------|
| قلة الطلب | عدد RFQ منخفض | تفعيل مقاولين Anchor |
| عمليات معقدة | Time to First Transaction طويل | تبسيط عملية الشراء + دعم |
| لا التزام | قلة الصفقات المتكررة | برامج إحالة + تنشيط |

## 4. مصفوفة المخاطر السريعة (Risk Heatmap)

```
الأثر ↑
  3 | R10 R8 |          | R1 R2
  2 |        | R6 R7 R9 R12 | R3 R4 R5
  1 |        | R11     |        
    +--------+---------+---------→ الاحتمال
         منخفض    متوسط    مرتفع
```

**قراءة المصفوفة:** R1 وR2 في المنطقة الحرجة (احتمال مرتفع × أثر مرتفع) — أولوية قصوى للتخفيف.
