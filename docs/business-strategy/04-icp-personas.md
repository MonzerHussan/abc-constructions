# ABC — Ideal Customer Profile (ICP)

**الغرض:** تحديد الشرائح المثالية للاستهداف الأولي لمنصة ABC في الإمارات  
**المنهجية المرجعية:** بناء الشخصية (Persona Development) + التحقق عبر Pilot

---

## 1. القطاعات الرئيسية الثلاثة

### القطاع 1: مقاولو المشاريع الصغيرة والمتوسطة (SMB Contractors)
**الوصف:** مقاولون مستقلون أو شركات صغيرة متوسطة الحجم (5-100 موظف) يعملون في مشاريع سكنية وتجارية وصغيرة.

### القطاع 2: الموردون وتجار مواد البناء الرقميون الطموحون
**الوصف:** موردون، موزعون، وكلاء يرغبون في توسيع وصولهم للعملاء لكن تواجههم تحديات التسويق والرقمنة.

### القطاع 3: شركات المقاولات الكبيرة (Enterprise)
**الوصف:** شركات مقاولات كبيرة (100+ موظف) بمشاريع كبيرة وحاجة لإدارة مشتريات مركزية.

---

## 2. تعريف Personas لكل قطاع

### Persona 1: "المهندس سعود" — مدير مشتريات/مشاريع في شركة مقاولات SMB

| البعد | التفاصيل |
|-------|----------|
| **الخلفية** | مهندس مدني، 30-45 سنة، يدير 2-5 مشاريع متزامنة |
| **الأهداف** | توفير الوقت والتكلفة في الشراء، ضمان جودة المواد |
| **الألم** | بحث مبعثر عن موردين، أسعار غير شفافة، تأخير تسليم |
| **السلوك** | يستخدم واتساب/هاتف/بريد للتواصل، يثق بالتوصيات |
| **احتياجات ABC** | سوق مركزي + مقارنة + موردون موثوقون + RFQ سريع |
| **عائق التبني** | قلة الخبرة الرقمية، الحاجة للدعم |
| **المؤشر (ICP Score)** | حجم شركة 10-100 موظف، شراء شهري >50 ألف درهم |

### Persona 2: "التاجر خالد" — مالك شركة توريد مواد بناء

| البعد | التفاصيل |
|-------|----------|
| **الخلفية** | تاجر مواد، 35-55 سنة، يدير كتالوج 500-5,000 منتج |
| **الأهداف** | الوصول لمقاولين جدد، زيادة المبيعات، تحسين التواجد الرقمي |
| **الألم** | تسويق مكلف، منافسة على السعر، إدارة طلبات يدوية |
| **السلوك** | يعتمد مندوبين ميدانيين + علاقات، حضور رقمي ضعيف |
| **احتياجات ABC** | كتالوج رقمي + وصول B2B + إدارة RFQ + تقارير |
| **عائق التبني** | الخوف من العمولات، التعقيد التقني |
| **المؤشر (ICP Score)** | 10-50 موظف، يملك كتالوج أو يرغب بإنشائه، يبحث عن عملاء |

### Persona 3: "المدير فاطمة" — مديرة مشتريات في شركة مقاولات كبيرة

| البعد | التفاصيل |
|-------|----------|
| **الخلفية** | مديرة مشتريات، 40-50 سنة، تدير سلسلة توريد لمشاريع كبيرة |
| **الأهداف** | توحيد المشتريات، تفاوض أفضل، تقليل المخاطر |
| **الألم** | عمليات معقدة، موردون متعددون بلا توحيد، نقص بيانات |
| **السلوك** | تستخدم ERP، عمليات رسمية، قرارات جماعية |
| **احتياجات ABC** | Enterprise solutions، API تكامل، تقارير، تفاوض |
| **عائق التبني** | تكامل مع الأنظمة الحالية، متطلبات مؤسسية |
| **المؤشر (ICP Score)** | 100+ موظف، مشتريات شهرية >1 مليون درهم |

---

## 3. Pain Points لكل فئة (مختصرة)

| الفئة | الألم الرئيسي | الألم الثانوي | الحل من ABC |
|-------|--------------|--------------|-------------|
| **SMB Contractors** | شراء مبعثر وبطيء | أسعار غير شفافة | سوق مركزي + مقارنة + RFQ |
| **Suppliers** | اكتساب عملاء مكلف | إدارة طلبات يدوية | قناة B2B + كتالوج + RFQ |
| **Enterprise** | مشتريات غير موحدة | نقص بيانات | حلول مؤسسية + API + تقارير |

---

## 4. معايير التقييم (ICP Score) وتقسيم الأولوية

### منهجية ترجيح (Score 0-100)

| المعيار | الوزن |
|---------|-------|
| حجم الشركة (المشتريات المحتملة) | 30% |
| شدة الألم | 25% |
| الجاهزية الرقمية | 15% |
| الاستعداد للدفع (WTP) | 20% |
| سهولة الوصول | 10% |

### الترتيب المبدئي للاستهداف

| الرتبة | القطاع | المبرر |
|--------|--------|--------|
| 1 | SMB Contractors | أعلى ألم + أكبر عدد + أسرع تبني |
| 2 | Suppliers (طموحون) | يمثلون عرض المنصة للمشترين |
| 3 | Enterprise Contractors | قيمة عالية لكن تبني أبطأ |

---

## 5. ملاحظات اعتماد (Validation)

| الفرضية | المصدر | ملاحظة |
|---------|--------|--------|
| SMB Contractors هم الشريحة الأساسية | Pilot (C-02, C-03, C-10) | يتأكد عند توفر البيانات |
| Suppliers يفضلون Freemium | Pilot (S-23) | يؤثر على التسعير |
| Enterprise يحتاج API/تقارير | مقابلات/توقعات | يضاف في Phase 2 |
