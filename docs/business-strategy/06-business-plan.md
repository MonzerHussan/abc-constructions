# ABC — Business Plan

**الشركة:** ABC — منصة B2B لتجارة مواد البناء والمشتريات  
**السوق:** الإمارات (المرحلة الأولى) → دول الخليج  
**الإصدار:** v1.0 (أرقام مبدئية — تُحدَّث بعد Pilot)

---

## 1. Executive Summary

| البند | المحتوى |
|-------|---------|
| **الرؤية (Vision)** | أن نكون المنصة الرقمية الأولى لمشتريات مواد البناء في منطقة الخليج |
| **الرسالة (Mission)** | تمكين المقاولين والموردين من شراء وبيع مواد البناء بكفاءة وشفافية |
| **المنتج** | سوق B2B يربط المقاولين بموردين موثقين مع RFQ ومقارنة أسعار |
| **السوق** | سوق مواد البناء الإماراتي (SAM تقديري ~15-25 مليار درهم) |
| **نموذج الإيراد** | اشتراكات + عمولات + Featured + إعلانات + خدمات AI مستقبلية |
| **الهدف الأولي** | استقطاب 100 مقاول + 200 مورد خلال السنة الأولى |
| **الطلب الاستثماري** | [تحديد بعد Financial Model] |

---

## 2. Vision & Mission

- **Vision:** قيادة التحول الرقمي لتجارة مواد البناء في الخليج
- **Mission:** توفير سوق موثوق وشفاف وفعال لمواد البناء يخدم كل أطراف المنظومة
- **القيم:** الشفافية، الثقة، الكفاءة، الابتكار

---

## 3. Business Model

| العنصر | الوصف |
|--------|-------|
| **النوع** | B2B Marketplace (تسويق ثنائي) |
| **الأطراف** | المشترون (مقاولون) — البائعون (موردون) |
| **التدفق** | عرض/طلب → تفاوض (RFQ) → صفقة → عمولة |
| **الفرق عن المنافسين** | تركيز SMB + RFQ + بيانات أسعار |

---

## 4. Market Opportunity

| المؤشر | التقدير |
|--------|---------|
| TAM | ~300-400 مليار درهم (سوق الإنشاءات) |
| SAM | ~15-25 مليار درهم (مواد B2B قابلة للرقمنة) |
| SOM (3 سنوات) | ~150-300 مليون درهم |
| المحركات | مشاريع ضخمة + تحول رقمي + فجوة السوق |
| الفجوة | شفافية الأسعار + RFQ يدوي + موردون غير موثقين |

---

## 5. Product Overview

### 5.1 الميزات الأساسية (MVP)

| الميزة | الوصف |
|--------|-------|
| **سوق المواد** | تصفح + بحث + تصنيف |
| **RFQ** | إنشاء وإرسال ومقارنة عروض |
| **ملف المورد** | كتالوج + تحقق + تقييمات |
| **مقارنة أسعار** | مقارنة عروض + تاريخ أسعار |
| **إدارة الطلبات** | تتبع حالة الطلب |
| **الدفع** | بوابة دفع B2B |

### 5.2 خارطة تطوير المنتج

| المرحلة | الإطار الزمني | الميزات |
|---------|--------------|---------|
| **MVP** | 0-6 أشهر | الأساسيات (سوق + RFQ + موردون) |
| **Phase 2** | 6-12 شهراً | دفع متقدم + تكامل ERP + تقارير |
| **Phase 3** | 12-18 شهراً | AI (تقدير كميات، تنبؤ أسعار) + لوجستيك + تمويل |

---

## 6. Execution Strategy

### 6.1 الاستراتيجية (اختراق سوق ثنائي)

| الخطوة | الوصف |
|--------|-------|
| **Side A: الموردون** | استقطاب موردين Anchor (فئة مواد محددة) مع كتالوجات |
| **Side B: المقاولون** | جذب مقاولين عبر عرض الموردين + فوائد RFQ |
| **التسلسل** | تأمين الموردين أولاً (العرض) ثم المقاولين (الطلب) |

### 6.2 خارطة تنفيذ مبدئية

| الفترة | الأهداف |
|--------|---------|
| **الأشهر 0-3** | بناء MVP + Pilot + اختبار |
| **الأشهر 3-6** | إطلاق بيتا + 50 مورد + 25 مقاول |
| **الأشهر 6-12** | توسع + 200 مورد + 100 مقاول |
| **السنة 2** | تكاملات + تعميق سوق الإمارات |
| **السنة 3** | توسع خليجي |
