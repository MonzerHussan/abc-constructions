# Sprint AI-1 · Deliverable 4 — Material Mapping (تطبيع المواد)

> **المسار:** AI & Integration Layer — Sprint AI-1
> **الحالة:** 📝 مواصفة — جاهزة للاعتماد
> **المرجع:** `MaterialCategory`/`UnitOfMeasure` في `prisma/schema.prisma` (ADR-019) · `03-boq-extraction-flow.md` · `09-ai-cost-management.md` §3.3
> **الغرض:** ربط النص الخام للبند بالفئات والوحدات **الموحّدة الموجودة فعلاً** — جسر المشروع ↔ السوق.

---

## 1. الهدف

تحويل `rawText` و`unit` الخام إلى `categoryId` (من `MaterialCategory`) و`unitId` (من `UnitOfMeasure`) — مع ثقة ومرادفات قابلة للتوسع. **التطبيع يحوّل "حديد تسليح 12م" → فئة حديد + وحدة طن.**

## 2. المصادر الموحّدة (القاموس المرجعي)

| الكيان | جدول Prisma | حقول المطابقة |
|--------|-------------|----------------|
| الفئة | `MaterialCategory` | `name`, `nameAr`, `slug` |
| الفئة الفرعية | `MaterialSubcategory` | `name`, `nameAr` |
| الوحدة | `UnitOfMeasure` | `name`, `nameAr`, `symbol` |

> **القيود (G1):** AI يقرأ هذه القوائم عبر Public Read Interface — **لا يكتب** فيها (لا إنشاء فئات من الاستخراج). أي فئة جديدة = إدارة في Product Catalog.

## 3. استراتيجية التطبيع (Hybrid)

```
rawText → (1) قواعد/قاموس → (2) متجهات (pgvector) → (3) LLM → نتيجة + ثقة
```

| الطبقة | تعمل عندما | التكلفة |
|--------|------------|---------|
| **1. قاموس مرادفات + قواعد** | تطابق مباشر (slug/مرادف معروف) | ~0 |
| **2. متجهات (Embedding)** | تشابه دلالي لنص مكرر/قريب | منخفضة |
| **3. LLM (عند الضرورة)** | `AMBIGUOUS`/غامض فقط | متوسطة |
| **استنتاج** | طبقات 1–3 تعطي نفس النتيجة | — |

**ترتيب التكلفة الحاكم (09 §2):** قواعد → متجهات → LLM — **لا يقفز أحدها**.

## 4. قاموس المرادفات (Synonym Dictionary)

| النوع | مثال |
|-------|------|
| مرادفات عربية | حديد تسليح = حديد سابك = حديد أملس = Rebar |
| صيغ كتابة | "م 12" / "12مم" / "12 mm" / "12مم" → قطر 12 |
| أسماء تجارية | تيوتو → أنابيب (فئة) |
| وحدات مرادفة | طن / ton / T → `UnitOfMeasure(id=طن)` |
| أخطاء OCR شائعة | استبدال حروف متشابهة عربياً |

> القاموس **بيانات داخل نطاق AI** (تُدار وتُقيس مدى تغطيتها) — لا تعديل على Product Catalog.

## 5. عتبات الثقة والقرار

| النتيجة | الثقة | السلوك |
|---------|-------|--------|
| مطابقة واضحة | ≥ 0.8 | `CLEAN` — بدون تدخل |
| تشابه متوسط | 0.5 – 0.8 | `LOW_CONFIDENCE` — يُعرض للمراجعة |
| غموض | خيارات متعددة | `AMBIGUOUS` — اختيار المستخدم |
| لا تطابق | < 0.5 | `UNRECOGNIZED` + `warnings[]` + اقتراح فئة يدوياً |

## 7. قياس الجودة

| المؤشر | الهدف |
|--------|-------|
| دقة التطبيع (Category) | ≥ 90% |
| دقة الوحدة | ≥ 95% |
| نسبة `UNRECOGNIZED` | < 5% |
| نسبة تتطلب LLM | < 15% (الحد الأقصى للالتزام بـ 09) |
| تحسين عبر الوقت | `AiFeedback` + نمو القاموس دورياً |

## 8. محاذاة التكلفة (09)

- **Cache:** أزواج (نص خام → نتيجة) متكررة تُخزَّن مؤقتاً (`cached=true`).
- **Embeddings مُعاد استخدامها:** لا إعادة حساب لنفس النص.
- **LLM فقط للغموض:** الهدف < 15% من الاستدعاءات (البند 7).
