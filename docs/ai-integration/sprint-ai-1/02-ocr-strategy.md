## 1. المبدأ

> **OCR هو الخيار الأخير لا الأول.** (09 §3.6 + Tiering)
> الترتيب في مرحلة `PARSE`: **Text Layer → قراءة جدولية → OCR** — ولا نصل للـ OCR إلا لصيغ لا تملك طبقة نص قابلة للقراءة.

| الحالة | المسار المختار |
|--------|----------------|
| PDF بنص | استخراج نص مباشر (بدون OCR) — الأرخص |
| XLSX/CSV | قراءة جدولية مباشرة — بدون OCR |
| PDF ممسوح / صورة | **OCR** — ضروري |

## 2. متى نستخدم OCR فعلياً

| المعيار | القاعدة |
|---------|---------|
| طبقة النص | غير موجودة أو نصوصها فارغة/غير قابلة للاستخراج |
| نوع المستند | لوحات BOQ ممسوحة، رسومات مواصفات، فواتير صور |
| اللغة | العربية (RTL) أساسية + إنجليزية + أردية — يجب اختبارها في الصور |
| الحجم | ≤ 20MB، حد صفحات للتعرف (مثال: ≤ 25 صفحة للتجربة) |

## 3. ترتيب المزوّدين (الاستراتيجية)

| المستوى | الخيار | متى | ملاحظة |
|---------|--------|-----|--------|
| 1 | نموذج Vision متعدد الوسائط (عبر `AiGateway`) | دقة عالية للجداول العربية/الإنجليزية | أغلى — للصفحات المهمة |
| 2 | محرك OCR متخصص (نص فقط) | استخراج نص خام رخيص | الأرخص لكل صفحة |
| 3 | نموذج محلي/إقليمي (Roadmap 5.3) | مستندات حساسة / تقليل التكلفة | يُفعل لاحقاً |

> اختيار المزوّد الفعلي **قرار تنفيذي عند الـ PoC** — هذه الوثيقة تحدد الترتيب والقيود لا اسم مزوّد بعينه.

## 4. خط الـ OCR المقترح

```
Image/Scan → (معالجة مسبقة) → OCR → (تنظيف) → نص منسّق → مرحلة EXTRACT (تسليم 3)
```

| الخطوة | الوصف |
|--------|-------|
| معالجة مسبقة | تحسين التباين، تدوير، إزالة ضوضاء (تحسين دقة العربية) |
| OCR | استخراج النص بمواضع الكلمات/الجداول (`boxes`) |
| تنظيف | إزالة الهوامش/التذييلات/التكرار، إعادة بناء الجداول |
| خرج | `ocrResult { blocks[], text, confidence }` — يُمرر لتسليم 3 |

## 5. عتبات الثقة والـ Fallback

| النتيجة | السلوك |
|---------|--------|
| ثقة ≥ 0.8 | يُكمل كالمعتاد (`COMPLETED`) |
| 0.5 – 0.8 | بنود تُعلَّم `lowConfidence` → `PARTIAL` مع `warnings[]` |
| < 0.5 | **Fallback:** إشعار للمستخدم بـ `AI_OCR_FAILED` + طلب ملف أوضح (أو نسخة رقمية) |

- **قاعدة حوكمة (08 §6):** النتيجة قائمة على OCR تُوسم `AiConfidenceBadge` بعرض مستواها — لا تقدَّم كنتيجة يقينية.
- **قاعدة أمان:** لا نرسل نص المستند لأغراض أخرى خارج خط الاستخراج دون موافقة (08 §9).

## 6. محاذاة التكلفة (09)

| الرافعة | التطبيق هنا |
|---------|-------------|
| Tiering | Text Layer قبل OCR؛ نموذج صغير للنص فقط؛ Vision للجداول المهمة فقط |
| حد الصفحات | لا OCR لمستندات ضخمة افتراضياً |
| Cache | نفس المستند (هاش) لا يُعاد OCR |
| Batching | صفحات مستند واحد في معالجة مجمّعة |

## 7. مؤشرات قياس (قبل الاعتماد النهائي)

| المؤشر | الهدف |
|--------|-------|
| دقة النص العربي/الإنجليزية (WER) | ≥ 95% للجداول النظيفة |
| معدل `PARTIAL` بسبب OCR | < 10% |
| تكلفة OCR/صفحة | ضمن حد يثبَّت بعد PoC |
| أخطاء بنود خاطئة بسبب OCR | يُدار عبر `lowConfidence` |
