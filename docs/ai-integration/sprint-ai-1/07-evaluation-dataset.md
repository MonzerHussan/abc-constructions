## 2. الـ Gold Dataset

### 2.1 ما هو
مجموعة ثابتة من مستندات BOQ **مُعلَّمة يدوياً** (الإجابة الصحيحة لكل بند: فئة، وحدة، كمية، حالة). تُعامل كمرجع لا يُغيّر دون إجراء مُوثَّق.

### 2.2 البنية المقترحة

```jsonc
// gold-dataset/v1/gold.manifest.json
{
  "version": "gold-boq-v1",
  "languages": ["ar", "en", "ur"],
  "source": "anonymized-imports + synthetic",
  "documents": [
    {
      "id": "doc_001",
      "file": "samples/ar/scanned-boq-001.pdf",
      "format": "pdf",                 // pdf | pdf-scanned | xlsx | csv | image
      "ocrRequired": true,
      "items": [
        {
          "rowIndex": 3,
          "rawText": "حديد تسليح 12م",
          "expectedCategoryId": "cat_steel_rebar",
          "expectedUnitId": "uom_ton",
          "expectedQuantity": 12.5,
          "label": "CLEAN"
        }
        // ...
      ]
    }
    // ...
  ]
}
```

### 2.3 تكوين المجموعة

| البعد | الهدف |
|-------|-------|
| الصيغ | PDF نص / PDF ممسوح / XLSX / CSV / صورة — تغطية كل المسارات (تسليم 1) |
| اللغات | عربي (أساسي) + إنجليزي + أردي — نسبة ≥ 60% عربي |
| الأنواع | بنود نظيفة، بنود غامضة (`AMBIGUOUS`)، وحدات غريبة، جداول معقدة |
| الصعوبة | 70% عادية / 20% معقدة / 10% شبه مستحيلة (تقيس حدود النظام) |
| الحجم الأدنى (مقترح) | **60 مستنداً** (25 معايرة/تطوير + 35 اختبار نهائي) — يُثبَّت عدده بعد Pilot |
| المصدر | **مجتهلة من بيانات حقيقية** (بإزالة الهوية — 08 §4) + مستندات تركيبية |

> **سياسة (Governance 08 §4):** لا تُستخدم بيانات مورد حقيقية للقياس دون إخفاء هوية.

### 2.4 إدارة النسخ
- كل نسخة (`gold-boq-v1`) **ثابتة** — تُوضع ضمن مستودع الاختبار (tests) مع `manifest`.
- أي إضافة/تعديل = نسخة جديدة (`gold-boq-v2`) مع سجل تغيير (Changelog).
- عند اعتماد نسخة جديدة: تُعاد معايرة أهداف المؤشرات معها.

## 3. المؤشرات المستهدفة

| المؤشر | التعريف | الهدف (مقترح) |
|--------|---------|---------------|
| **Extraction Accuracy** | نسبة البنود المستخرجة الصحيحة (بنود فعلية، بدون تذييلات/رؤوس) | ≥ 90% |
| **Material Classification** | نسبة البنود التي طُبِّعت للفئة الصحيحة (من المُعرَّفة) | ≥ 90% |
| **Unit Detection** | نسبة البنود التي حُدِّدت وحدتها الصحيحة | ≥ 95% |
| **Human Review Rate** | نسبة البنود المطلوب مراجعتها (LOW_CONFIDENCE + AMBIGUOUS) | ≤ 20% |
| **Unrecognized Rate** | نسبة `UNRECOGNIZED` (مُستبعدة) | < 5% |
| **Quantity Accuracy** | صحة قيم الكميات (ضمن ±1% أو ±صفر عشري) | ≥ 97% |

> الأهداف مبدئية وتُثبَّت بعد أول قياس على Gold — كلها ضمن نطاقات `04-material-mapping.md` §7.

## 4. آلية التحقق (بوابة قبول التحسينات)

```
تغيير (نموذج/قاموس/Prompt/OCR/إصدار)
        │
        ▼
1. تشغيل على Gold Dataset (نفس الإصدار المرجعي)
        │
        ▼
2. حساب المؤشرات (§3) قبل/بعد
        │
        ▼
3. مطابقة عتبة القبول:
   • لا تراجع في أي مؤشر جوهري
   • التحسن في المؤشر المستهدف
        │
        ▼
4. اجتياز؟ → معاينة يدوية على 5 مستندات متنوعة → اعتماد → ترقية الإصدار (تسليم 6)
   رفض؟ → إعادة التطوير
```

### 4.1 عتبات إلزامية

| الشرط | التفصيل |
|-------|---------|
| لا انحدار | لا يهبط أي مؤشر جوهري عن السابق بأكثر من **1 نقطة مئوية** |
| تحقق الهدف | المؤشر المستهدف من الترقية يتحسن ≥ عتبة محددة مسبقاً |
| تغطية اللغات | النتائج مُقاسة في اللغات الثلاث (لا تحسين عربي على حساب إنجليزي) |
| عينة يدوية | معاينة بشرية على 5 مستندات متنوعة قبل الاعتماد (08 §6) |

### 4.2 الحالات المسموحة عند الانحدار

| الحالة | القرار |
|--------|--------|
| تحسين كبير في مؤشر + انحدار طفيف في آخر | تقبل بمراجعة (تُوثَّق) |
| انحدار في أي مؤشر جوهري بدون تعويض | **رفض الترقية** |
| غموض | تُعاد المعاينة اليدوية |

---

## 5. القياس الدوري على الإنتاج

| المؤشر | المصدر (الإنتاج) |
|--------|-------------------|
| Human Review Rate الفعلي | `AiFeedback` + حالات البنود في النتائج |
| Unrecognized Rate | نتائج `AiJob` (warnings) |
| رضا المستخدم | `AiFeedback.rating` (1–5) |
| Fallback Rate | `AiUsage.status = FALLBACK` (09 §8) |

- **تقرير شهري (مقترح):** مقارنة إنتاج مقابل Gold — أي انحراف > 5 نقاط يفتح تحقيقاً (08 §10).

## 6. أدوات وأماكن (مقترح للتنفيذ)

- مجموعة Gold داخل `tests/ai/gold/` مع `manifest` + سكربت تقييم (`scripts/ai/eval.mjs`).
- أمر تقييم: `npm run ai:eval` → تقرير JSON/Table (قبل/بعد).
- يُدمج في CI كـ **بوابة اختيارية** (لا تُبطئ التطوير اليومي — تُشغَّل قبل أي ترقية مُعتمدة).
