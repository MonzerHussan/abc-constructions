## 1. الغرض

مصدر معرفة موحّد للوكلاء: استرجاع (Retrieval) من فهارس المتجهات + القواعد، **مدعوم بالمصادر (Grounded)**، دون وصول مباشر للبيانات (G1).

## 2. مبدأ G3 في RAG

| الطبقة | الدور | التكلفة |
|--------|-------|---------|
| قواعد/مرشحات (Filters) | تقييد النطاق (منظومة/فئة/منطقة) | ~0 |
| استرجاع متجهي (pgvector) | أقرب التطابقات الدلالية | منخفضة |
| **Re-rank** | إعادة ترتيب المرشحين | منخفضة |
| توليد (LLM) | صياغة الإجابة/التوصية | حسب الحاجة فقط |

> **قاعدة 09 §2:** الـ LLM يُستخدم للتوليد فقط بعد استرجاعٍ جيد — لا تخمين.

## 3. مصادر المعرفة (Knowledge Sources)

| الفهرس | المحتوى | يخدم وكلاء |
|--------|---------|-------------|
| `jobs` | وظائف (Career) | Job Seeker, Recruiter |
| `learning` | دورات/شهادات/محتوى | Student, Trainer |
| `products` | منتجات/فئات/مواصفات | Supplier, Contractor, Procurement |
| `suppliers` | ملفات موردين (قدرات) | Contractor, Procurement |
| `tenders` | مناقصات/مستندات | Contractor, Supplier |
| `boq-docs` | مستندات BOQ المرفوعة | Contractor, Procurement, Logistics |
| `docs` | سياسات/شروط المنصة | CS, Legal, Sales |
| `signals` | إشارات سلوك مجملة (Analytics) | Marketing, Analytics |

## 4. بنية الاسترجاع (Retrieval Flow)

```
سؤال/سياق → (1) مرشحات (منظومة/نطاق) → (2) متجهات topK
          → (3) Re-rank → (4) تجميع سياق → (5) LLM (توليد + اقتباس)
```

| الخطوة | التفصيل |
|--------|---------|
| مرشحات | نطاق الوكيل/المنظمة/المنظومة (خصوصية — G1) |
| متجهات | `pgvector` — embeddings من البوابة (S1) |
| Re-rank | نموذج ترتيب خفيف أو قواعد (نتيجة مدمجة) |
| اقتباس | كل مقطع مسترجع يُشار إليه `sourceId` (Grounded — 08) |
| توليد | LLM يصوغ الإجابة مع ربط الاقتباسات + `AiConfidenceBadge` (G4) |

## 5. استراتيجية التجزئة (Chunking)

| النوع | حجم القطعة | التداخل |
|-------|------------|---------|
| نصوص قصيرة (وظائف/منتجات) | كيان كامل | — |
| مستندات طويلة (عقود/سياسات) | 800–1000 رمز | 10% |
| جداول BOQ | بند لكل قطعة + سياق عنوان القسم | — |

- القطع تُخزَّن مع **metadata** (منظومة، فئة، org/عام، إصدار) للفلترة والأذونات.

## 6. التحديث والتحدّث (Refresh)

| الحدث | الإجراء |
|-------|---------|
| نشر/تعديل كيان | إنشاء/تحديث متجه (عبر الحدث — G2) |
| حذف/إخفاء | تعطيل القطعة (`isActive=false`) |
| إصدار نموذج embedding جديد | إعادة حساب تدريجي + مقارنة جودة (تسليم 7 AI-1) |
| خطة دورية | إعادة فحص القطع الميتة (عدم التطابق) أسبوعياً |

## 7. الأذونات داخل RAG (خصوصية)

| القاعدة | التفصيل |
|---------|---------|
| مرشحات إلزامية | لا استرجاع خارج نطاق الوكيل/المنظمة |
| بيانات خاصة بالمنظمة | متجهات `orgId` — لا تظهر لمنظمات أخرى |
| بيانات عامة | قابلة للاسترجاع بلا قيود org |
| PII | لا تُضمَّن في المتجهات العامة (08 §4) |

## 8. محاذاة التكلفة (09)

- Embeddings مُعاد استخدامها (لا إعادة حساب لنفس النص).
- **Cache** للاستعلامات المتكررة (نفس الهاش) عبر البوابة.
- Re-rank أولاً ثم LLM — LLM فقط على أعلى K.

## 9. قياس الجودة

| المؤشر | الهدف (مقترح) |
|--------|----------------|
| استرجاع ذي صلة (Precision@5) | ≥ 85% |
| نسبة إجابات بلا مصادر (خطر هلاوس) | < 5% |
| إعادة حساب متجهات عند التحديث | ≤ 24 ساعة |
| Fallback للمصادر القديمة | تُعرض مع تحذير |
