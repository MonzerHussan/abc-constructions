## 1. الغرض

ذاكرة موحّدة تتيح للوكلاء **التعرّف على السياق مع الوقت** (تفضيلات، سجل، حقائق) دون إعادة إدخال — مع احترام كامل للخصوصية والاحتفاظ (08).

## 2. أنواع الذاكرة (Memory Types)

| النوع | الوصف | مثال | الحيوية |
|-------|-------|------|---------|
| **Short-term (جلسة)** | سياق المحادثة الحالية | آخر 10 أسئلة للمقاول | جلسة واحدة (TTL) |
| **Working** | سياق مهمة قيد التنفيذ | خطوات خطة RFQ النشطة | نهاية المهمة |
| **Episodic (سجل)** | إجراءات/أحداث سابقة للمستخدم | "رفع BOQ الأسبوع الماضي" | مؤقت + ملخصات |
| **Semantic (معرفة)** | حقائق/تفضيلات دائمة | "يفضّل موردين في الرياض" | طويل الأمد (بموافقة) |
| **Procedural (مهارة)** | معرفة الوكيل كيف يفعل | "قواعد تطبيع BOQ" | ثابتة (إصدارات) |

## 3. نطاقات الذاكرة (Scopes)

| النطاق | خاص بـ | أمثلة |
|--------|--------|-------|
| `user` | مستخدم واحد | تفضيلات الباحث عن عمل |
| `org` | منظمة | تفضيلات شراء المقاول |
| `agent` | معرفة الوكيل | إجراءات التنفيذ |
| `ecosystem` | منظومة كاملة | اتجاهات السوق (مجملة) |
| `platform` | نظام كامل | سياسات عامة |

> **قاعدة العزل:** لا يقرأ وكيل ذاكرة نطاق أعلى من إذنه. `org` لا يقرأ `user` لوكيل آخر دون سبب + تدقيق (08).

## 4. التخزين المقترح

```prisma
model AiMemory {
  id        String   @id @default(cuid())
  scope     String   // user | org | agent | ecosystem | platform
  scopeId   String   // userId / orgId / agentId ...
  kind      String   // SHORT | WORKING | EPISODIC | SEMANTIC | PROCEDURAL
  key       String   // مفتاح (مثال: "preferred_region")
  value     Json
  embedding Unsupported("vector(1536)?")?   // للاسترجاع الدلالي
  version   Int      @default(1)
  isActive  Boolean  @default(true)
  expiresAt DateTime?                        // TTL (قصيرة المدى)
  createdById String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  @@index([scope, scopeId, kind])
}
```

> **نموذج جديد داخل نطاق AI** — لا تعديل Domain (القيود المعتمدة). يُعتمد في Sprint AI-2b.

## 5. القراءة/الكتابة (عبر MemoryService S4)

| العملية | الوصف |
|---------|-------|
| `read({scope, kind, key})` | قراءة مباشرة |
| `search({query, scope, kind, topK})` | استرجاع دلالي (متجهات) |
| `write({scope, kind, key, value, ttl?})` | كتابة (بإذن + تدقيق) |
| `forget(scope, kind, key)` | حذف/إبطال (خصوصية — 08 §9) |
| `summarize(episodic)` | تلخيص سجل قديم بدل الاحتفاظ الخام |

## 6. دورة الحياة والاحتفاظ

| النوع | TTL الافتراضي |
|-------|---------------|
| Short-term | 24 ساعة |
| Working | نهاية المهمة |
| Episodic | 90 يوماً (ثم ملخص + حذف) |
| Semantic | بموافقة صريحة — قابلة للحذف دائماً |
| Procedural | يُدار بالإصدارات (تسليم 6 من AI-1) |

- **مبدأ "الحق في النسيان":** المستخدم يستطيع مسح أي ذاكرة تخصه (08 §9).
- **التدقيق:** كل كتابة/حذف ذاكرة تُسجَّل (ADR-009).

## 7. أمان الذاكرة

| القاعدة | التفصيل |
|---------|---------|
| لا بيانات PII حساسة في `Semantic` دون تشفير/موافقة | 08 §4 |
| لا ذاكرة مشتركة عبر المنظمات | عزلة `scopeId` |
| حدود حجم لكل وكيل/مستخدم | منع التضخم (09) |
| وكلاء المنصة (L3) لا يقرؤون ذاكرة مستخدمين فردية بلا إذن | استثناء موثق |
