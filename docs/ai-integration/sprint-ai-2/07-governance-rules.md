## 1. المبدأ

`08-ai-governance.md` هو الأساس؛ هذه القواعد تعالج **خصوصيات تعدد الوكلاء**: الهوية، التعارض، التنسيق، التصعيد، والحدود بين الوكلاء.

## 2. هوية الوكيل ومسؤوليته

| القاعدة | التفصيل |
|---------|---------|
| **وكيل = مسؤولية** | كل وكيل له مالك/جهة مسؤولة (من Sprints التسليمات) |
| **لا انتحال** | المخرجات تحمل هوية الوكيل دائماً (لا "النظام" الغامض) |
| **الشفافية** | كل وكيل يقدّم نفسه للمستخدم عند الحاجة (G4) |
| **حدود الدور** | لا وكيل يتجاوز قدراته المسجلة في التصنيف (تسليم 1) |

## 3. حدود التنسيق (Coordination)

| القاعدة | التفصيل |
|---------|---------|
| **التفويض الهرمي فقط** | Orchestrator يفوّض — لا وكيل يفوّض لآخر مباشرة |
| **تعارض النتائج** | إذا تناقض وكيلان → تصعيد إلى Orchestrator + إشراك بشري (08 §6) |
| **أولوية القرار** | قواعد العمل المعتمدة > اقتراح وكيل |
| **لا حلقات** | حد أقصى لعدد التفويضات/الخطوات (منع حلقة بلا نهاية) |

## 4. حدود الأدوات والإجراءات

| القاعدة | التفصيل |
|---------|---------|
| **أدنى صلاحية** | وكيل يملك فقط الأدوات المكشوفة له (تسليم 5) |
| **لا كتابة مباشرة** | أي كتابة عبر أداة موثَّقة + تدقيق (G2/08) |
| **رفض تلقائي** | تجاوز الحصص/الحدود → رفض + سبب |
| **L3 إلزامي** | إجراءات مالية/قانونية/شراء = موافقة بشرية (08 §6) |

## 5. التصعيد البشري (Escalation Matrix)

| الموقف | التصعيد إلى | المهلة |
|--------|-------------|--------|
| انخفاض ثقة الناتج | المستخدم (يعرض البدائل) | فوري |
| إجراء HIGH_WRITE | الدور المحدد (`approvalRole`) | حسب السياسة |
| تعارض وكيلين | مدير المنظومة | فوري |
| شكوى/مخاطرة أمنية | Security Agent + بشري | فوري |
| طلب خارج نطاق | رفض + توجيه لمنظومة أخرى | — |

## 6. التدقيق والتتبع

| البند | القاعدة |
|-------|---------|
| كل تفويض/خطوة | مسجَّل بهوية وكيل + `requestId` (ADR-009) |
| كل أداة Write | سجل كامل (من/ماذا/متى/لماذا) |
| كل قرار بشري | سجل موافقة/رفض + المسؤول |
| تقارير دورية | مراجعة سلوك الوكلاء (تردد/تكلفة/أخطاء) في Sprint Reviews |

## 7. معدلات وحصص (Rate/Quota)

| البند | القاعدة |
|-------|---------|
| لكل وكيل | حد استدعاءات/دقيقة (Rate Limit) |
| لكل منظمة | حصة شهرية (`AiQuota` — 09) |
| لكل منظومة | ميزانية قصوى (توقف عند السقف) |
| Kill Switch | تعطيل أي وكيل فوراً عند الحادثة (08 §10) |

## 8. الامتثال والخصوصية

| القاعدة | التفصيل |
|---------|---------|
| لا PII عبر الوكلاء بلا موافقة | 08 §4 |
| ذاكرة محترمة للخصوصية | تسليم 4 (الحق في النسيان) |
| وكلاء L3 لا يقرؤون بيانات فردية بلا إذن | استثناء موثق |
| التزام الثلاثية اللغوية | كل المخرجات ar/en/ur |

## 9. دورة حياة الوكيل (Agent Lifecycle)

```
PROPOSED → APPROVED → ACTIVE → (PAUSED / DEPRECATED) → RETIRED
```

| الحالة | القاعدة |
|--------|---------|
| `PROPOSED` | طلب وكيل جديد (AI Council) |
| `APPROVED` | اعتماد التصنيف + الأذونات + التكلفة |
| `ACTIVE` | خلف Feature Flag `FF_AGENT_*` |
| `PAUSED` | تعطيل مؤقت (مخاطرة/تكلفة) |
| `DEPRECATED` | استبدال/دمج — إشعار مسبق |
| `RETIRED` | إزالة + أرشفة السجلات |
