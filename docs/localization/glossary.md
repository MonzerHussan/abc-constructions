# ABC Localization Glossary — D10 (v1.1)

> المرجع الموحّد لمصطلحات المنصة باللغات الثلاث. كل مفهوم له ترجمة رسمية واحدة — لا ترجمات متعددة. المصدر الوحيد لمراجعي الترجمة (D10).

## ملاحظات

- الأكواد الفنية (SKU, RFQ-001, ISO, KYC) تُترك لاتينية دائماً — **لا تُترجم**.
- وحدات القياس تُترك لاتينية (m³, kg, TON) — **لا تُترجم**.
- الأرقام: عربي `١٢٣` · أردي `۱۲۳` · إنجليزي `123` عبر `Intl.NumberFormat`.
