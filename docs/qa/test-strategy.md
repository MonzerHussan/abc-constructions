# إستراتيجية اختبار الجودة — منصة ABC (Beta)

**الإصدار:** 0.1.0  
**التاريخ:** 2026-08-01  
**النطاق:** تجهيز المنصة للدخول في مرحلة Beta (تحقق من الجودة والأمان والأداء والبنية).

---

## 1. الهدف

تحديد نهج الاختبار متعدد الطبقات لمنصة ABC، وربطه ببوابات الجودة الآلية (CI/CD) بحيث لا يخرج أي تغيير للـ Beta دون اجتياز الفحوصات الإلزامية.

## 2. هرم الاختبار

| الطبقة | الأدوات | الموقع | الإلزامية في CI |
|---|---|---|---|
| اختبارات الوحدات | Vitest 4 | `src/modules/**/__tests__/` | نعم |
| اختبارات البنية (Architecture) | Vitest | `tests/architecture/` | نعم |

| فحص الاعتماديات | `npm audit` | — | نعم (حرجة فقط) |

## 3. البوابات الإلزامية قبل Beta

1. `npm run typecheck` — نظيف (0 أخطاء).
2. `npm test` — جميع الاختبارات (وحدة + بنية + تكامل + أمان) ناجحة.
3. `npm run build` — build إنتاجي ناجح مع Prisma generate.
4. `npm audit --audit-level=critical` — لا ثغرات حرجة غير معالجة.
5. التغطية: **لا تراجع** عن خط الأساس (Lines ≈ 80%، Branches ≈ 61%).
6. lint: 208 errors + 280 warnings موروثة — **مُوثَّقة كمخاطر**، تُدفع تدريجياً، لا تُعطِّل CI حالياً.

## 4. التغطية بالفروع الرئيسية

- **المشتريات:** RFQ (إنشاء → إرسال → فتح → ترسية)، العروض (Quotation)، أوامر الشراء.
- **شبكة الموردين:** إنشاء ملف المورد، التحقق (UNVERIFIED → BASIC → VERIFIED)، العلاقات.
- **كتالوج المنتجات:** إنشاء منتج، العروض السعرية (Offering).
- **المصادقة:** تسجيل (قيود الأدوار)، دخول (حدود معدل)، MFA، جلسة 7 أيام.
- **الأمان:** تصعيد صلاحيات، رفع ملفات (magic bytes)، حماية endpoints، رؤوس الأمان.

## 5. أوامر التشغيل

```bash
npm test                  # كامل (وحدات + بنية + تكامل + أمان)
npm run test:watch        # وضع المراقبة
npm run test:coverage     # مع تقرير التغطية
npm run test:architecture # البنية فقط
npm run test:e2e          # Playwright (يحتاج خادماً قائماً)
npm run typecheck         # فحص الأنواع
```

## 6. القيود والمعالجات المعروفة

- اختبارات التكامل تعتمد على mocks ولا تلمس قاعدة بيانات حقيقية — تُكمل بـ E2E ضد PostgreSQL في CI.
- E2E يتطلب تشغيل `next build` + `next start`؛ في CI يتم ذلك في مرحلة منفصلة.
- التغطية لا تشمل مكونات الواجهة (UI) حالياً — تُضاف عند بناء اختبارات المكوّنات (RTL/Testing Library) في مرحلة لاحقة.
