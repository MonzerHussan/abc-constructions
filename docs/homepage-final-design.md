# الصفحة الرئيسية — التصميم الختامي (Final Homepage Spec)

> مواصفات معتمدة للصفحة الرئيسية للمنصة `/projects/ABC`.
> نسبة إلى المعاينة `docs/design-review/01-home.html` + تعديلات أيام العمل الأخيرة.

## البنية العامة (Desktop ≥ lg)

تخطيط فوق شاشة واحدة لا يمر عبر التمرير (لا يوجد شريط علوي منفصل):

```
┌─────────────────────────────────────────┬──────────────────────┐
│  الهيدر (يمتد من بعد العمود الأيسر       │                      │
│  حتى آخر الشاشة)                        │                      │
│  المناقصات·السوق·المجتمع ... اللغة·دخول·إنشاء حساب │              │
├─────────────────────────────────────────┤   العمود الأيسر      │
│       الكاروسيل في المنتصف              │   (260px — بنفس      │
│                                         │   عرض عمود DeepSeek)│
├─────────────────────────┬───────────────┤                      │
│   العمود الأوسط          │  العمود الأيمن │                      │
│   (كاروسيل فقط)          │  (منطقتان    │                      │
│                         │  يتحكم بهما   │                      │
│                         │  الأدمن)      │                      │
├─────────────────────────┴───────────────┴──────────────────────┤
│   منطقة الإعلانات — شريط بعرض المساحة الكاملة للمحتوى           │
│   يمتد من العمود الأيسر إلى آخر الشاشة (تحت الأوسط والأيمن)     │
│   (1-4 إعلانات: نص / صورة / فيديو / مزيج)                      │
├────────────────────────────────────────────────────────────────┤
│  (بعد التمرير) يبدأ المحتوى الديناميكي الإضافي — AdsBanner وضغوط │
└─────────────────────────────────────────────────────────────────┘
```

## العناصر بالتفصيل

### 1. العمود الأيسر — يمتد من أعلى الشاشة إلى أسفلها
- خلفية داكنة (gradient hero) بعرض ثابت **260px** (بنفس عرض عمود صفحة DeepSeek).
- **اتجاهه يتبع اللغة**: بالإنجليزية (LTR) يقع يسار الشاشة، وبالعربية (RTL) ينعكس ويقع يمين الشاشة — كل شيء ينقلب كمرآة، النص العربي يتجه RTL داخل الحاويات.
- `main` شبكة `lg:grid-cols-[260px_1fr]` بلا `dir` مجبر — فينعكس مع `dir` الغلاف الخارجي (`dir={dir}`).
- محتواه فقط:
  - الشعار في الأعلى (الصورة فقط — بدون أحرف «ABC» بجانبه).
  - زر الزائر/الحساب أسفل العمود.
  - المسافة بين الشعار وزر الزائر: منطقة إدارة حرة للأدمن (نص / صورة / فيديو) — تُدار من لوحة الأدمن → إدارة الصفحة الرئيسية → «العمود الأيسر» عبر حقول `leftBlockType` (text|image|video|none) + العنوان/النص tri-lingual + رابط الصورة + رابط الفيديو + الصورة المصغرة + رابط الانتقال + `leftBlockEnabled` (إخفاء). تُصرف قيمها للواجهة عبر `content.leftBlock` من `GET /api/homepage`.
- لا يوجد أي شريط/هيدر علوي فوقه — يبدأ من أعلى الشاشة.

### 2. الهيدر — شريط علوي بعرض بقيّة الشاشة
- يبدأ الهيدر من **بعد العمود** مباشرة (ملاصقاً له عند حافته) ويمتد حتى **آخر الشاشة**.
- **لا تمرير أفقي** داخل الهيدر، والمنطقة الرئيسية `h-[100dvh]` بلا تمرير رأسي.
- **بجانب العمود** — قوائم منسدلة، تبدأ بالمناقصات ثم السوق ثم المجتمع:
  - **المناقصات**: المشاريع · المواد · التوصيل · المنتجات
  - **السوق**: المشاريع · المواد · التوصيل · المنتجات
  - **المجتمع**: الوظائف · التدريب
  - (بالعربية RTL ينعكس الترتيب كمرآة؛ المناقصات تبقى الأقرب للعمود.)
- **الطرف المقابل للعمود** — تبدأ بإنشاء حساب ثم تسجيل الدخول ثم اللغة (من الحافة):
  - **إنشاء حساب**: زر/قائمة منسدلة بـ **9 فئات** بالترتيب:
    جهة · شركة · مالك · استشاري · مقاول · مقاول فرعي · مورد · تاجر · أفراد
    — اختيار أي فئة يفتح **نموذج التسجيل في منتصف منطقة الكاروسيل** (لا انتقال لصفحة مستقلة؛ الفئة تُرسَل كدور `role` لـ `/api/auth/register` ثم تسجيل دخول تلقائي → `/onboarding`).
  - **تسجيل الدخول**: رابط مباشر.
  - **اللغة**: قائمة (العربية · English · اردو)
- القوائم المنسدلة لا تظهر **خلف الكاروسيل** (`header z-20` + القوائم `z-50` بمنطقة تراصّ معزولة).
- في DOM: `NavDropdown` أولاً ثم مجموعة الحساب/اللغة — فيظهر التنقل ملاصقاً للعمود، ومجموعة الحساب في الطرف المقابل، وتنعكس الجهات تلقائياً حسب RTL/LTR.
- **زوايا 90° بالكامل**: حاوية الهيدر `rounded-none` (بارتفاع منخفض `px-3 py-1.5`، `gap-2`) وكل أزراره وقوائمه المنسدلة `rounded-none` — NavDropdown وLanguageSwitcher وCreateAccountMenu (أزرار `px-2.5 py-1.5`) — يُقاس الارتفاع الحالي 48px (EN/AR x=0..1172).

### 4. الكاروسيل — بين العمودين وبين الهيدر والإعلانات
- يملأ مساحة `العمود الأوسط` **تماماً**: بين العمود الأيسر (260px) والعمود الأيمن (منطقتا الأدمن 280px) أفقياً، وبين الهيدر وشريط الإعلانات عمودياً (يقاس EN: x=288..1172, y=56..748 بعد تقليص الهيدر إلى 48px؛ RTL منعكس x نفس النطاق، y نفسه) — بدون أي شاشة دخول فوقه.
- هوامش قليلة (`gap-2`) بين الأعمدة/الهيدر/الإعلانات، وزوايا **90 درجة** (`rounded-none` على الحاوية واللوحة).
- **تحكم كامل من الأدمن** — كل شريحة من أنواع:
  - `type` (image | text | video) + `title`/`subtitle` tri-lingual + `imageUrl` + `videoUrl` + `posterUrl` (غلاف الفيديو) + `linkUrl` + `isActive` + `sortOrder`.
  - نص: خلفية متدرجة بنص العنوان/الوصف في الوسط؛ صورة: كالسابق مع «ابدأ الآن»؛ فيديو: فيديو HTML5 صامت/حلقي/تلقائي مع غلاف، والنص فوقه.
  - الإدارة من تبويب «الشرائح (Carousel)» في لوحة الصفحة الرئيسية.

### 5. نموذج التسجيل / الدخول — يظهر فوق منطقة الكاروسيل (قرار تصميمي مُحفَّظ)
- **لا توجد** أي شاشة تسجيل/دخول ثابتة فوق الكاروسيل، ولا أي انتقال لصفحة مستقلة عند فتح النماذج.
- **مبدأ مُعتمَد (لا يُغيّر):** الضغط على «إنشاء حساب»/«تسجيل الدخول» **لا يغادر الصفحة الرئيسية أبداً** — النموذج يظهر وكأنه طبقة فوق منطقة الكاروسيل ويُغلق ببساطة.
- **إنشاء حساب**: الضغط على «إنشاء حساب» في الهيدر ثم اختيار **فئة من القائمة** يفتح `RegisterInline` كبطاقة **في منتصف مساحة الكاروسيل** (خلفية معتمة خلفها)، يدخل فيها المستخدم اسمه/جواله/بريده/كلمته/شركته ثم يُنشئ الحساب (الدور = الفئة المختارة عبر `ACCOUNT_CATEGORY_ROLE`). زر الإغلاق يعيد الكاروسيل. — محطّى بحالة `pendingRegister`.
- **تسجيل الدخول**: زر «تسجيل الدخول» في الهيدر يفتح `LoginInline` بنفس الطراز فوق الكاروسيل (بريد + كلمة مرور → فحص `check-credentials` ثم `signIn`، مع خطوة المصادقة الثنائية TOTP عند الحاجة) — محطّى بحالة `pendingLogin`، وعند النجاح يُغلق النموذج ويبقى المستخدم في الصفحة الرئيسية.
- **العمود الأيسر (زر الضيف)**: «تسجيل الدخول» يفتح `LoginInline`، و«إنشاء حساب» يفتح `RegisterInline` (فئة `accountCategoryOwner` كمفتاح افتراضي) — كلاهما فوق الكاروسيل ولا ينقلا لمكان آخر.
- **هام (منع تكرار الخطأ):** لا ترجع أيًا من روابط الدخول/الإنشاء إلى صفحات `/projects/ABC/auth/login` أو `/projects/ABC/auth/register` من الصفحة الرئيسية — كل المسارات تمر عبر `pendingLogin`/`pendingRegister` وطبقتي `LoginInline`/`RegisterInline` أعلى الكاروسيل (`bg-black/55 fixed منزالة فوق منطقة الكاروسيل`).
- النموذجان `rounded-none` و`bg-secondary-500` بأزرار ذهبية وقيم ربط من `translations.ts` (بما فيها `invalidCredentials`/`loginFailed`/`invalidMfaCode`/`mfaCode`/`mfaVerify`/`show`/`hide` بـ 3 لغات).

### 6. العمود الأيمن — مناطق يقسمها الأدمن (1-3)
- العمود الأيمن (280px) يُقسَّم إلى **1 أو 2 أو 3 مناطق** يقسمها الأدمن، أو تبقى منطقة واحدة — كل منطقة يمكنها استيعاب **نص / صورة / فيديو / مزيج** (قياس: EN x=0..280, y=56..748 مقسّمة بالتساوي؛ RTL معكوسة بالجهة نفسها).
- البيانات من `data.zones` (جدول `HomepageZone` — هجرة `20260817_140000_abc_add_homepage_zones`)، كل منطقة: `type` (text|image|video|mixed) + العنوان/الوصف tri-lingual + `body` (نص/مزيج) + `imageUrl` + `videoUrl` + `posterUrl` + `linkUrl` + `animation`.
- العارض `ZoneCard` (شبيه `AdCard`) بزوايا **90 درجة** (`rounded-none`) و`flex-1` فيملأ العمود؛ عدد المناطق يحدد التقسيم (1→يملأ الكل، 2→نصفان، 3→ثلاثة).
- في لوحة الأدمن (تبويب «مناطق العمود الأيمن»): إضافة مناطق حتى **3 كحد أقصى**، ترتيب، حذف، ونوع كل منطقة (نص/صورة/فيديو/مزيج).
- العمود الأوسط المجاور يعرض الكاروسيل فقط (نُقلت الإعلانات منه إلى الشريط السفلي).

### 7. منطقة الإعلانات — شريط سفلي بعرض كامل (1-4 إعلانات)
- شريط مستقل يمتد **من العمود الأيسر إلى آخر الشاشة** (أي بعرض مساحة المحتوى) ويقع **تحت العمودين الأوسط والأيمن** أسفل شاشة العرض الأولى — يصرف من `data.ads`.
- **سيطرة كاملة من الأدمن**: تبويب «الإعلانات» في لوحة الأدمن (إضافة/تعديل/حذف/ترتيب/إخفاء).
- كل إعلان من أنواع: **نص / صورة / فيديو / مزيج**:
  - `type` (image|text|video|mixed) + `title`/`subtitle` tri-lingual + `body` tri-lingual (للنص/المزيج) + `imageUrl` + `videoUrl` + `posterUrl` (غلاف الفيديو) + `linkUrl` + `animation` + `isActive` + `sortOrder`.
  - يُعرض عبر مكوّن `AdCard` (فيديو HTML5 أصلي بلا مكتبات خارجية، أيقونة تشغيل، رابط خارجي للفيديو أو `linkUrl`).
- التخطيط حسب العدد: `grid` — 1 عمود عند إعلان واحد، وعمودان عند 2، و3 عند 3، و4 عند 4 (عرض الشريط كامل).
- **زوايا 90°**: كل بطاقة `AdCard` بـ `rounded-none` (`gap-2` بينها)، والشريط ملاصق لما فوقه بلا هامش (`mt-0`) — يُقاس y=756..900 (h=144).
- **الانعكاس كمرآة**: عند اللغة العربية (RTL) ينعكس الشريط مع بقية الجهات (يقاس: EN x=276..1440، AR x=0..1164 — منطبقان انعكاساً مع العمود الداكن يساراً/يميناً).
- `AdsBanner` أسفل التمرير يعرض نفس الإعلانات من خلال `AdCard` بعدد أعمدة ديناميكي.

### 8. ما بعد شاشة العرض الأولى (كله تحت سيطرة الأدمن)
- بعد إغلاق `main` (h-[100dvh]) يبدأ المحتوى الديناميكي الإضافي بعد التمرير، كل قسم منه **يُدار من الأدمن** (تبويب «محتوى الصفحة» في لوحة الصفحة الرئيسية → قسم «المحتوى تحت شريط الإعلانات حتى الفوتر»)، وقيم الترجمة من واجهة الأدمن بصيغة tri-lingual:
  - **قسم «أبرز ما في المنصة»** — `showHighlights` + عنوان `highlightsTitle*` (عربي/إنجليزي/أردو)، يعرض الكاروسيل (شرائح `data.slides`).
  - **AdsBanner** — نفس إعلانات `data.ads` (مدارة من تبويب «الإعلانات»).
  - **شريط الإحصائيات** — `showStats` + 4 إحصائيات (`stat1..stat4`: قيمة + تسمية tri-lingual)، تُصرف محلياً من واجهة الأدمن إلى `below.stats` (قيمة/تسمية بلغة العرض).
  - **قسم الفيديوهات** — `showVideosSection` + عنوان `videosSectionTitle*`، يعرض فيديوهات `data.videos`.
  - **الفوتر** — `showFooter` + نبذة `footerAbout*` + بريد/هاتف/عنوان (`footerEmail`/`footerPhone`/`footerAddress*`).
- نقاط التحكم الجديدة في نماذج `HomepageContent` المفصّلة — هجرة `20260817_150000_abc_add_homepage_below_ads_sections` — تجلب عبر `GET /api/homepage` (`content.*` محلياً حسب اللغة).
- **تقليل الهوامش الكلي إلى النصف**: كل الحشوات/الفجوات بـ page.tsx والمكوّنات مخفّضة إلى نصفها السابق (صفحة من `py-12`→`py-6`، `gap-6`→`gap-3`، بطاقات `p-4`→`p-2`، `py-10`→`py-5`...)، فوترة مضغوطة `py-6` وفجوة `gap-4`، شريط الإعلانات `py-4` — قياسات بعد التخفيض: هيدر 48px، مناطق العمود y=52..400 h=348، شريط الإعلانات y=756..900.
- **اللوحة اللونية** مطابقة للهوية: `--secondary` ذهبي `#d4a017` (الأزرار/الرابط الابتدائي `bg-secondary-500`... تُقاس gold rgb(212,160,23)) و`--accent` برتقالي `#f97316` — يُستخدم فقط للتمييز (القيم الإحصائية وتلميحات النص) فلا يظهر البرتقالي بكثرة.
- **زوايا العمود الأيسر 90°**: زر الزائر/الحساب (`AccountMenu`) في أسفل عمود الحدود أصبح `rounded-none` و`p-2` مع قائمته المنسدلة `rounded-none` (يُقاس 0px لكل منهما)، وزر «إنشاء حساب» في الهيدر `rounded-none`، والشعار/بطاقات محتوى العمود الأوسط `rounded-none`.

## ملاحظات تقنية
- `RTL/LTR` عبر `dir` والـ Logical Properties — **البنية تنعكس كمرآة حسب اللغة** (الإنجليزية LTR: العمود يساراً؛ العربية RTL: العمود يميناً وكل شيء ينقلب)، والغلاف الخارجي `dir={dir}`.
- التخطيط: `<main>` شبكة `lg:grid-cols-[260px_1fr]` (بالعربية RTL ينعكس فيقع العمود الداكن يميناً)؛ داخل مساحة المحتوى: الهيدر بعرض كامل ثم شبكة `lg:grid-cols-[1fr_280px]` (الأوسط: كاروسيل | الأيمن: منطقتا الأدمن) ثم **شريط الإعلانات** بعرض المساحة الكاملة أسفلهما — كل ذلك داخل `lg:h-[100dvh]` بلا تمرير.
- فئات إنشاء الحساب (9): مفاتيح `accountCategoryEntity/Company/Owner/Consultant/Contractor/Subcontractor/Supplier/Trader/Individual`.
- المحتوى الديناميكي (أعمدة الأدمن + الإعلانات + الكاروسيل) يُجلب من `GET /api/homepage` (حقول `ads`, `slides`, `videos`, `content`).
- منطقة الإعلانات: شريط سفلي يعرض أول 4 إعلانات (`data.ads.slice(0, 4)`) عبر `AdCard` بتخطيط 1/2/3/4 أعمدة حسب العدد؛ أسفل التمرير `AdsBanner` يعرضها بالطريقة نفسها.
- نموذج الإعلان في قاعدة البيانات (`Ad`): `type` (+ `body/bodyEn/bodyUr` للنص/المزيج) + `videoUrl`/`posterUrl` للفيديو + `imageUrl` (افتراضي `""`) — هجرة `20260817_120814_abc_add_ad_media_fields`. واجهة الأدمن (تبويب «الإعلانات»): منتقي النوع وحقول النص/الفيديو/الغلاف مشروطة بالنوع؛ الـ API: POST يقبل `type/body*/videoUrl/posterUrl` (لا يشترط `imageUrl` بعد الآن) وPATCH سمّى الحقول الجديدة.
- شرائح الكاروسيل في قاعدة البيانات (`CarouselSlide`): أُضيف `type` (image|text|video) + `videoUrl`/`posterUrl` + `imageUrl` (افتراضي `""`) — هجرة `20260817_124053_abc_add_carousel_media_types`؛ واجهة الأدمن (تبويب «الشرائح») منتقي النوع وحقول الفيديو/الغلاف، والـ API يتقبلها POST/PATCH، و`HomepageCarousel` يعرض النص/الصورة/الفيديو تلقائياً.
- نموذج التسجيل المضمّن: `RegisterInline` بالهيدر → `CreateAccountMenu` يرسل الفئة (`onSelect`) → `pendingRegister` يفتح البطاقة في منتصف الكاروسيل (خلفية `bg-black/55`) → `POST /api/auth/register` بدور الفئة ثم `signIn` → `/onboarding`.
- العمود الأيمن بمنطقتين: يرتبط بحقول قابلة للإخفاء (نص/صورة/فيديو) يديرها الأدمن.
- العمود الأيمن غير مرتبط بالفيديوهات — يحمل `data.zones` من جدول `HomepageZone` (تبويب «مناطق العمود الأيمن» في لوحة الأدمن، حد 3 مناطق، كل منطقة نوعها نص/صورة/فيديو/مزيج ويحمل نصف/ثلث/كامل العمود حسب العدد).
- المحتوى تحت شريط الإعلانات → الفوتر: حقول `HomepageContent` الجديدة (`showHighlights`/`highlightsTitle*`/`showStats`/`stat1..4Value+Label*`/`showVideosSection`/`videosSectionTitle*`/`showFooter`/`footerAbout*`/`footerEmail`/`footerPhone`/`footerAddress*`) — هجرة `20260817_150000_abc_add_homepage_below_ads_sections`؛ واجهة الأدمن (تبويب «محتوى الصفحة») تتحكم بها كلها.
- `CONTENT_FIELDS` في `src/app/api/admin/homepage/route.ts` تشمل الحقول الجديدة بحيث يحفظها PUT.
