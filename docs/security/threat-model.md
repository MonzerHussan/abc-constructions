**المنهجية:** STRIDE المعدّلة لنطاق Beta (وضع هجومي واقعي مقابل أصول المنصة).

## 1. الأصول (Assets)

| الأصل | الحساسية | الأثر إن اختُرِق |
|---|---|---|
| قاعدة بيانات PostgreSQL (`abc_constructions`) | عالية جداً | بيانات أعمال، عقود، عروض أسعار |
| حسابات المستخدمين (أدوار أعمال) | عالية | احتيال، انتحال، تصعيد صلاحيات |
| ملفات رفع (توثيق الموردين) | متوسطة | هجمات تخزين XSS/تنفيذ |

## 2. التهديدات ومعالجتها

### T1 — تصعيد الصلاحيات عبر التسجيل
- **وصف:** إنشاء حساب بدور ADMIN.
- **الإصلاح:** `selfRegisterSchema` + قائمة `SELF_REGISTRATION_ROLES` (تحقق Zod). ✅
- **متبقٍ:** تحقق إداري يدوي عند الحاجة لأدوار إدارية.

### T2 — هجوم تخمين كلمات المرور / Brute-force
- **وصف:** تكرار محاولات الدخول.
- **الإصلاح:** rate limiting على `check-credentials`, `authorize`, MFA. ✅
- **متبقٍ:** قفل حساب (lockout) بعد N محاولات فاشلة — توصية لمرحلة لاحقة.

### T3 — رفع ملفات خبيثة (Stored XSS / تنفيذ)
- **وصف:** رفع HTML/JS أو ملف لا يتطابق محتواه مع نوعه.
- **الإصلاح:** فحص magic bytes + رفض MIME متعارض + اسم عشوائي + حد 10MB. ✅
- **متبقٍ:** فحص الفيروسات عند التوسع (اختياري).

### T4 — الوصول غير المصرح لنقاط الـ seed/الإدارة
- **وصف:** استدعاء `/api/seed/*` أو `/admin` من مستخدم عادي.
- **الإصلاح:** منع seed في production + اشتراط ADMIN/SUPER_ADMIN (route + middleware). ✅

### T5 — كشف الأسرار في المستودع
- **وصف:** تسريب كلمة مرور DB أو مفاتيح.
- **الإصلاح:** تنظيف `.env.example` + `.env` خارج git. ✅
- **متبقٍ:** تدوير الأسرار السابقة، إضافة فحص أسرار في CI (gitleaks) — توصية.

### T6 — انتحال الجلسة / جلسات طويلة
- **وصف:** سرقة كوكي أو بقاء جلسة دائمة.
- **الإصلاح:** maxAge=7 أيام؛ اعتماد كوكي HttpOnly/Secure (افتراضي Auth.js). ✅
- **متبقٍ:** مراقبة أجهزة الدخول وإلغاء الجلسات عن بعد — لاحقاً.

### T7 — تجاوز أذونات الوصول إلى بيانات (IDOR)
- **وصف:** الوصول لسجل غير مملوك بواسطة معرف.
- **الإصلاح:** التحقق من الملكية في خدمات RFQ/Quotation/Profile (اختبارات B/SP). ✅ جزئياً
- **متبقٍ:** تدقيق شامل لكل نقاط API (توصية جولة قادمة).

### T8 — هجمات الحرمان من الخدمة (DoS)
- **وصف:** إغراق نقاط المصادقة.
- **الإصلاح:** rate limiting أساسي. ⚠️ جزئي
- **متبقٍ:** حماية CDN/WAF، قيود حجم الطلبات على مستوى الخادم.

### T9 — حقن SQL / NoSQL
- **وصف:** إدخال أوامر عبر معاملات.
- **الإصلاح:** Prisma ORM مُهيأ (استعلامات معاملية) + تحقق Zod على المدخلات. ✅ (تخفيف بنيوي)

## 3. مصفوفة المخاطر المتبقية

| التهديد | الاحتمالية | الأثر | الأولوية المتبقية |
|---|---|---|---|
| T7 IDOR | منخفضة (تحقق جزئي) | عالية | جولة ما بعد Beta |
| T8 DoS | متوسطة | متوسطة | بعد Beta (WAF) |
| T2 lockout | منخفضة | متوسطة | بعد Beta |
| T5 سحب الأسرار القديمة | منخفضة | عالية | فوري (إجراء تشغيلي) |

## 4. الخلاصة

لا توجد تهديدات حرجة مفتوحة تمنع دخول Beta **بشرط**: (أ) تدوير أي أسرار سابقة، (ب) تثبيت rate limiter، (ج) إغلاق/حماية endpoints الإدارية، وهي كلها منجزة أو مؤكدة في هذه الجولة.
