## 3. لماذا لا تمنع Beta؟

- جميعها **transitive** وليست في شجرة تشغيل مسار الأعمال الحرجة (auth, procurement, catalog).
- لا توجد ثغرة **Critical**.
- مسار الصور (sharp) ليس مسار بيانات حساسة، ويمكن تقييد استخدامه.
- GitHUb Actions يتضمن خطوة `npm audit --audit-level=critical` — لن يسمح بمرور أي Critical جديدة.

## 4. إجراءات مقترحة

1. **فوري:** ترقية `sharp` إلى آخر إصدار (`npm update sharp`).
2. **دوري:** فتح Dependabot/ورينة تحديث تلقائية للاعتماديات.
3. **أثناء الترقيات:** مراجعة `npm audit` بعد كل تحديث لـ Next.
4. إضافة خطوة `npm audit --audit-level=high` كبوابة بعد سداد الديون الحالية.
